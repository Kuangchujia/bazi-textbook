# Practice Booklet (No Answers)

This directory holds 63 practice questions from the seventeen lessons of the *Foundation Textbook of the Four Pillars and Eight Characters*. The original questions are copied as they stand; no standard answers, reference answers or worked solutions are provided.

The "corresponding textbook" and "original section" under each question serve only to locate the study material; they are not hints at an answer.
