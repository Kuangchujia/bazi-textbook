# 연습 문제 책자(정답 없음)

이 디렉터리에는 『사주팔자 기초 교재』 열일곱 과의 연습문제 63도가 수록되어 있습니다. 교재의 원제를 그대로 옮겼으며, 표준 정답·참고 정답·해제 과정은 제공하지 않습니다.

각 문제 아래의 「대응 교재」「원제 소절」은 학습 내용의 위치를 찾는 용도일 뿐, 정답 힌트가 아닙니다.
