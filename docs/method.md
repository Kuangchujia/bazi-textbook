# 一体多面

一体多面，是指同一种太极之气因动静不同而分阴阳；放到具体命局中，其轻重与指向会随观察维度而改变。

## 三步次序

**定维度**　维度不定，结论必乱。先问看它的哪一面：性格、六亲、健康、事业。同一正官，断性格看正义感，断婚姻看夫星得位，断健康看官星被冲克。这一步对应第 3—9 课，天干、地支与十神类象。

**看力量**　力量不对，全盘皆废。同一十神，强弱不同则天差地别。正官有力为权柄，无力为空衔；财星身强为富，身弱为累。这一步对应第 14—15 课，旺衰抑扶。

**观组合**　组合不同，格局迥异。十神从不单独行事。正官见印为官印相生，见伤官则伤官见官。这一步对应第 10—12 课，十神组合三部曲。

## 执一而论错在哪

见比劫就想到夺财，见七杀就想到凶灾。可比劫既夺财，也是合作伙伴；七杀虽攻身，有制便是偏官。

第 13 课有一个例子：一个八字里印绶被财所破。断学业，印被财坏，不吉；断事业，要看官星是否得力。同一个八字，领域一换，结论就换。若只按「财坏印」一句断下去，事业那一面就被抹掉了。

吉不永吉，凶不尽凶，全在角度与组合之间。

## 适用范围

三步次序是读盘的路子，不是断语的公式。维度没定就落结论，或者拿一个十神去套所有领域，都不在一体多面的用法之内。它给的是同一个命局在不同层面上的读法，不给现成断语。
