# 课程与研修

教材公开，教学另设。本页说明三级的范围与衔接，不承诺课程以外的结果。

## 三级体系

| 层级 | 教材 | 内容范围 | 状态 |
|---|---|---|---|
| 基础班 | 四篇十七课，约十二万字 | 排盘、阴阳五行、天干地支、十神、格局、旺衰、大运流年 | 教材已公开 |
| 研修班 | 十八章，二十四万余字 | 取格、用神、相神、体用、成败救应、刑冲会合、岁运，以及各专项格局 | 教材另行成书 |
| 弟子班 | 第三层级 | 以正式教学资料为准 | 暂不开放招生 |

## 免费与收费的界线

教材原文、练习题、结构化附录与基础知识阅读，在本站长期免费开放，不设付费门槛。讲义讲解、作业点评、阶段答疑与个案指导属于教学服务，按课程另行组织。

收费的不是知识的入口，而是教师投入的时间与指导。费用标准、课时安排、答疑次数、作业批改范围与退款规则，以每期正式通知为准，本页不列价目。

## 学习路径

先读教材，把盘排对；再按课次做练习，把概念认清；确认需要系统推进时，再进入授课环节。研修班以基础班为前提，取格与用神的判断次序建立在对干支、十神、旺衰的熟悉之上。

教材可按原课次自学。是否跟课，取决于你需要的反馈密度，而不是内容是否可得。

## 边界

不承诺学完即可准确推断，也不承诺财富、婚姻或事业方面的结果。课程只提供理论训练与方法讨论。
