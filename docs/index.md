# 四柱八字基础教材

邝楚嘉（嘉言一得）基础班四篇十七课、12+万字。此处是基础班教材原文的单一内容源与在线阅读站；研修班十八章、二十四万余字，另行编排，不在本库。

全书从阴阳五行与干支起手，依次讲天干五合、地支关系、八字排法、长生十二宫、十神排法、十神类象、十神组合、旺衰抑扶、神煞与大运流年。每课自成一段，前后有承接，可从头读，也可按需单取一课。
