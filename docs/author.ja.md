# 嘉言一得について

## 著者紹介

邝楚嘉（Chujia Kuang）、筆名は嘉言一得、広東省掲陽出身の独立研究者であり伝統術数の教育者です。1996年から伝統術数を研習し、長年にわたり四柱八字と奇門遁甲の学習、理論研究および教学体系の整理に従事し、2013年から講義を開いて教えています。

伝統術数の研究と教学のほか、著者は中国の伝統暦法と歴史天文の研究、および潮汕民俗と地方文化のデータ整理も行っており、関連する成果は専門サイト、公開データリポジトリおよび学術アーカイブを通じてそれぞれ公開されています。

## 学問と教学の姿勢

八字の学習はいくつかの段階に分けられます。早年は典籍を読み、中頃はフォーラムで長年命例を見続け、のちに師に学び、その後は講義資料を編み、講義を開きました。これらの段階は互いに置き換わる関係ではなく、前の段階の基礎は後でも常に必要になります。

四柱八字の学習は用語の暗記と口訣の当てはめに留まってはなりません。まず暦法、排盤、陰陽五行、天干地支、十神の基礎を身につけ、次に十神の組合せ、格局、用神と歳運との関係を理解します。次序を逆にすると、後へ進むほど混乱します。

実際の分析では命局全体の構造関係を見ると同時に、時代背景、地域環境、現実の条件を合わせて考量します。単一の十神、単一の記号、あるいは孤立した一句の断語では、全体の分析に代わることはできません。

## 教材

『四柱八字基礎教材』は四篇十七課、12万字以上で、二十余年の排盤実践と十余年の教学経験の整理です。主軸は著者自身の基礎教学体系であり、伝統典籍は補足と延伸読書として扱います。古籍の原文を引く箇所には本文に沿って書名を記し、それ以外は個人の経験と教学上の見解です。

## 専門分野

**四柱八字**：基礎班では排盤、陰陽五行、天干地支、十神、格局、旺衰、大運流年を扱い、研修班では取格、用神、相神、体用、成敗救応、刑沖会合と歳運を扱います。基礎班は十七課、12万字以上で、[教材本文](textbook/L01.md) を参照してください。研修班は十八章、二十四万字余りで、別途成書され、本ライブラリには含まれません。

**奇門遁甲**：師承の系譜、分析の思路、その場起盤の記録は [jiayanyide.com](https://jiayanyide.com/) に収録されています。

**暦法と古天文**：二十四節気の交節時刻、干支の換歳、二十八宿などの公開データセットは [kuangchujia.com](https://kuangchujia.com/) に収録されています。
