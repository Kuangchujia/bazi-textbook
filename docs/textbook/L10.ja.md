# 第10課 十神の組合せ（一）·格局の枠組みと分析方法

[简体中文](/textbook/L10/) ｜ [繁體中文](/zh-hant/textbook/L10/) ｜ [English](/en/textbook/L10/) ｜ **日本語** ｜ [한국어](/ko/textbook/L10/)

## 一、禄・刃・月劫の概念

### 1.1 禄（臨官）

禄とは、日元が地支において臨官の状態にあることをいう。禄が月令にあるものを建禄といい、力量が最も強い。日支にあるものを専禄、時支にあるものを帰禄、年支にあるものを歳禄といい、力量はこの順に減じてゆく——建禄 ＞ 専禄 ＞ 帰禄 ＞ 歳禄。禄は吉神であり、穏健にして力あり、人が社会のなかで着実に前進してゆく基盤を表す。ただし建禄が月令にある者は、禄を単独で用いることはできない——必ず別に財官を取って用神としなければならない。実戦では、禄は年・月・日・時のいずれの柱に位置していても、すべて旺と称してよい。

### 1.2 刃（陽刃）

陽刃（YangRen）：陽干（甲・丙・戊・庚・壬）が地支において帝旺となる状態をいう。五行の力は盛極まって亢じ、亢ずれば悔あり。ゆえに四凶神の一つに列せられ、制伏してはじめて用をなしうる。

| 陽干 | 刃 | 原理 |
| --- | --- | --- |
| 甲木 | 卯 | 木は卯に帝旺す |
| 丙火 | 午 | 火は午に帝旺す |
| 戊土 | 午 | 戊は丙と同じく論ず |
| 庚金 | 酉 | 金は酉に帝旺す |
| 壬水 | 子 | 水は子に帝旺す |

刃は猛虎のごとし——制なければ身を傷つけ、制あれば権となる。刃を制するには官殺（GuanSha）を第一とする。いわゆる「殺刃双顕」の格局は、しばしば最も迫力があり、最も大事を成しうる人である。

### 1.3 月劫

月劫：陰干（乙・丁・己・辛・癸）が地支において帝旺となる状態をいう。その力は陽刃に及ばず、禄に相当する。ゆえに「月劫」と称する。月劫は制伏を要せず、護持を主とする。

| 陰干 | 月劫 | 原理 |
| --- | --- | --- |
| 乙木 | 寅 | 木は寅に帝旺す（陰干は逆行） |
| 丁火 | 巳 | 火は巳に帝旺す |
| 己土 | 巳 | 己は丁と同じく論ず |
| 辛金 | 申 | 金は申に帝旺す |
| 癸水 | 亥 | 水は亥に帝旺す |

力量の比較：刃 ＞ 禄 ＞ 劫。刃は凶神にして暴、禄は吉神にして穏健、月劫は両者の中間に位する。

二十余年従事してきたうえでの重要な注意——羊刃と陽刃の別：初心者が最も混同しやすいところであるが、実は一方は神煞、一方は十神である。羊刃は神煞であり、十天干が地支の帝旺に逢うものはすべて羊刃である。陽刃は十神であり、五陽干のみに特有である。五陽干の帝旺の位では両者が重なる（例えば甲が卯を見るのは陽刃であると同時に羊刃でもある）が、陰干には羊刃のみがあって陽刃はない——断じて同一視してはならない。

邝楚嘉按：禄・刃・劫は格局分析の「第一の門」である。建禄が月令にある者は、身は弱くないが禄を単独で用いることはできず、必ず別に財官を取らなければならない。陽刃が月令にあればなおさら慎重を要する——私が見てきた富貴の格局のうち、殺刃双顕の者は最も迫力があるが、刃に制なき者は最も事を起こしやすい。実戦で陽刃を見たときの第一の反応は、これを制する官殺があるかどうかである。あれば権柄を握り、なければ暴虎出柙となる。

## 二、通根と透干の概念

本課の中核・全課程の綱領：通根と透干は、十神の力量を理解する第一の鍵である。天干は動を主り、地支は静を主る——この一動一静のあいだに、ある十神が「真にその力あり」か「虚にその表あり」かが決まる。この概念は本教材のこれ以降の全課程を貫き、旺衰を論じ、真偽を弁じ、吉凶を断ずるたびごとに、常にこれを用いる。通根・透干は入門は易しく極めるは難しい。必ず本節を繰り返し研読し、条件反射に至るまでにせよ。

### 2.1 定義

透干——地支の蔵干が天干に再現すること。例えば巳に丙・戊・庚が蔵され、天干に丙・戊・庚のいずれかが再び見えれば、すなわち透干である。透ずれば顕彰し、透ぜざれば潜蔵す。

通根——天干が地支に同じ五行の根を持つこと。例えば天干が甲で、地支の寅に甲が蔵されていれば、すなわち通根である。根あれば実、根なきは虚。

蔵支不透——地支に蔵干はあるが、天干に透出していないこと。例えば巳に丙火が蔵されていても、天干の四柱に丙がまったく見えなければ、すなわち蔵支不透である。蔵支不透の力量は内に隠れ、歳運が引き透してはじめてその能を顕すのを静かに待つ。

虚浮——天干が地支に通根せず、名ありて実なし。福力は半減する。

截脚——同じ柱の地支が天干を剋すること。例えば丙子では、子水が丙火を剋し、天干は困を受ける。

蓋頭——同じ柱の天干が地支を剋すること。例えば丙申では、丙火が申金を剋し、地支は制を受ける。

### 2.2 実例対照

丙火を例に、同じ丙火が異なる地支のなかで示す力量の差異を見る。

- 丙午（通根透干）——午に丁・己が蔵され、丙火は午に通根し、根気は深厚である
- 丙申（蓋頭）——丙火が申金を剋し、天干が地支を抑えつける
- 丙子（截脚）——子水が丙火を剋し、天干が地支に牽制される
- 丙辰（虚浮）——辰は土にして、丙火の光を暗く晦し、丙の根気は実ならず

邝楚嘉按：天干は動を主り、透出すればすなわち用いるに足る。地支は静を主り、人元が天干に透出しなければ施すところがない。天干は外在の表現、地支は内在の支えである。天干が虚浮にして根なければ、鏡花水月のごとく名ありて実なし。地支の蔵干が透出しなければ、才を懐いて遇わず、空しく一世を嗟く。ただ透干通根——外に表現あり内に根基あるもののみが、才華を施展し、強にして用ありとなる。

天干と地支の作用関係は、八字予測の第一の難題であり、また一切の技法の基礎である。この術を極めんとすれば、両者の動静・虚実・載透を深く究めなければならない。

## 三、八字の分析方法

### 3.1 三大分析ステップ

第一歩：透出した組合せを見る（矛盾を定める）。天干は八字の顔である——どの十神が透出しているかが、命局の主要な矛盾を直接決める。まず天干上のすべての十神を列挙し、一つひとつ吉凶を判断し、次に互いに制化するかどうかを見る。

例示：月干に丁火が透出し、壬水が丁に合するのは、比劫（BiJie）が財を奪う象である。食傷（ShiShang）が財を生じ、官殺が財を護る歳運は吉。地支の未戌の刑、子午の衝は、その家庭・健康状態を決める。

第二歩：月支の主気を見る（環境を定める）。月令の主気を基準とし、吉凶の判断は同一の原則による——吉神は順、凶神は制を宜しとする。

例示：戊が午月に生ずるのは陽刃であり、凶神は制を要する。七殺（QiSha）をもって刃を制するを宜しとする——財が殺を生ずれば吉、殺を剋すれば凶。地支の午未の合、寅亥の合は、その家庭・健康を定める。

第三歩：地支の状態を見る（事象を定める）。地支における刑衝剋害破は具体的な生活事象を決める。刑は官非・傷病を主り、衝は動揺・分離を主り、害は暗傷・矛盾を主り、破は破壊・損耗を主る。

### 3.2 分析の口訣

「官あれば先ず官を論じ、官なければ方に用を論ず。格々推詳し、殺を以て重と為す——殺を化して権と為さば、何ぞ用を損ずるを愁えん」。まず官殺を論じ、正官（ZhengGuan）を重しとする。官殺なければ他の十神を論ず。吉神は順用し、凶神は逆制する。

> 

邝楚嘉按：三步法は二十余年の実戦のなかで最も安定した分析の枠組みである——矛盾を定め→環境を定め→事象を定める。三歩を歩み終えれば、全局の骨格はすでに立っている。多くの学生は第一歩でつまずき、十神の山を前にして手のつけようがない。次の一句を銘記せよ——「官あれば先ず官を論じ、官なければ方に用を論ず」。正官は一生の本筋であり、官が清ければ全局が清む。

## 四、四吉神と四凶神

『喜忌篇』の喜忌総綱——「官煞兩停，喜者存之，憎者棄之」、すなわち官と煞が両停するときは、喜ぶべきものを存し、憎むべきものを棄てよ、という。『四言独歩』に云う——「官煞重逢，制伏有功；如行帝旺，遇之不凶」、すなわち官煞が重ねて逢えば制伏に功があり、帝旺を行くも之に遇いて凶とならない、と。——吉凶は絶対の標識ではなく、制化こそが鍵である。

吉神と凶神の区別は絶対ではない——官殺が重ねて逢っても、制伏あれば権となり、制伏なければ禍となる。鍵は制化にあり、標識にはない。

### 4.1 四吉神

四吉神は人生における最も核心的な福気の源——事業・学識・健康・財富——を表す。吉神が用事するときは保護を要し、軽々しく剋奪・破壊されてはならない。

| 吉神 | 代表意義 | 得用の表現 | 天敵 |
| --- | --- | --- | --- |
| 正官 | 事業・栄誉、男命は子女、女命は夫 | 貴人に見出され、上司に引き立てられる | 傷官（ShangGuan） |
| 印綬（YinShou） | 家庭・父母、学歴・資格、不動産 | 目上の貴人の助力、家庭の得力 | 財星 |
| 食神（ShiShen） | 健康・智慧、女命は子女、福寿 | 才華の施展、後輩の信認 | 梟神（XiaoShen） |
| 財星（CaiXing） | 財運・財富、男命は妻、父 | 妻家の助力、夫の運を旺んずる | 比劫 |

### 4.2 四凶神

四凶神は剋制・争奪・破壊の力量を表す。凶は絶対ではない——制あれば権柄に化し、制なければ禍は免れ難い。

| 凶神 | 代表意義 | 制伏の方法 | 無制の禍 |
| --- | --- | --- | --- |
| 七殺 | 小人・是非、意外の傷害、女命は情夫 | 食神の制殺、印星の化殺 | 身を攻める災禍 |
| 陽刃（劫財／JieCai） | 盗賊・情敵、財星を剋奪 | 官殺の制刃 | 破財・傷身 |
| 傷官 | 是非を弄し、傲慢・叛逆 | 印星の制傷 | 官を損じ上を犯す |
| 梟神 | 食神を剋傷し、食の生財を阻む | 財星の制梟 | 食を奪い福を損ず |

邝楚嘉按：四吉四凶の本質は、まさに「同一の本体×異なる次元＝異なる結論」である。正官は財と印に逢えば貴格となり、傷と殺に遇えば禍端となる。七殺は食の制あれば権柄となり、制なきは災禍となる——同一の十神も制化の有無によって吉凶は迥かに異なる。吉神は護るを要し、凶神は制するを要す。すべては格局のうちにある。

## 本章小結

1. 禄刃劫——禄（臨官）、刃（陽干の帝旺）、月劫（陰干の帝旺）。力量は刃＞禄＞劫。刃は制伏を要し、禄は保護を要し、月劫は禄に似る。
2. 通根透干——通根透干＝実力あり名気あり、虚浮＝名気ありて実力なし、蔵支不透＝実力ありて名気なし。
3. 八字の分析方法——三步：天干の透出組合せ（矛盾を定める）→月支の主気（環境を定める）→地支の刑衝剋害破（事象を定める）。まず官殺を論ず。
4. 四吉神——正官（事業・栄誉）、印綬（家庭・学識）、食神（健康・才華）、財星（財富・父）。保護を要し、剋奪されてはならない。
5. 四凶神——七殺（小人・是非）、陽刃（強盗・情敵）、傷官（叛逆・叛徒）、梟神（継母・内通者）。制伏してはじめて権柄となる。
6. 四吉神の配合——食神の制殺生財、財星の生官、正官が財と印の佐輔を得ること、印綬が官の生を受けて身を護ること。詳細は第11課。

## 練習

### 練習1：禄刃劫

問い：力量が最も強いのは刃・禄・劫のいずれか。

1. A. 刃 ＞ 禄 ＞ 劫
2. B. 禄 ＞ 刃 ＞ 劫
3. C. 劫 ＞ 禄 ＞ 刃
4. D. 刃 ＞ 劫 ＞ 禄

???+ "答え"
    正解：A
    力量の比較：刃 ＞ 禄 ＞ 劫
    刃：陽干の帝旺、力大にして暴
    禄：臨官の状態、穏健にして力あり
    月劫：陰干の帝旺、その力は刃に及ばず、禄と同じ

### 練習2：通根透干

問い：天干が地支に通根しないことを何というか。

1. A. 通根
2. B. 虚浮（虚透）
3. C. 蓋頭
4. D. 截脚

???+ "答え"
    正解：B
    天干が通根しない → 虚浮／虚透（無力）
    截脚：地支が天干を剋す、例えば丙子
    蓋頭：天干が地支を剋す、例えば丙申

### 練習3：吉凶神の識別

問い：以下のうち、すべてが四吉神である組はどれか。

1. A. 正官、七殺、食神、財星
2. B. 正官、印綬、食神、財星
3. C. 七殺、傷官、梟神、陽刃
4. D. 正官、正財、正印、傷官

???+ "答え"
    正解：B
    四吉神：正官・印綬・食神・財星
    四凶神：七殺・陽刃（劫財）・傷官・梟神
    四吉神：正官印綬食神財／四凶神：七殺陽刃傷官梟
