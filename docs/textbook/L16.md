## 一、吉神类神煞

吉神类神煞是八字中起正面辅助作用的星神。学神煞的第一步，就是把下面这几个最常见的吉神记熟。

### 1.1 天乙贵人

天乙贵人是最重要的一颗吉神，主逢凶化吉、遇难呈祥。查法以日干为准，地支见即为有贵人。口诀虽然看起来像歌谣，但记熟了对排盘判断很有帮助。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 甲戊并牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，庚辛逢虎马，此是贵人方 |
| 查法 | 以日干起贵人，地支见者为是 |
| 作用 | 逢凶化吉之星——四柱有贵人，遇事有人帮，遇危难之事有人解救 |

### 1.2 天德贵人

天德贵人以月令为准来查，不同月份出生的人有不同的天德。天德主一生平稳、少病少灾，是与月德齐名的吉祥神煞。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 正月生者见丁，二月生者见申，三月生者见壬，四月生者见辛，五月生者见亥，六月生者见甲，七月生者见癸，八月生者见寅，九月生者见丙，十月生者见乙，十一月生者见巳，十二月生者见庚 |
| 查法 | 凡四柱年月日时上见者为有天德贵人 |
| 作用 | 人有天德贵人，一生平稳，少病少灾 |

### 1.3 月德贵人

月德与天德并称"天月二德"，古人认为二德是仁慈善良之象。如果凶煞（如七杀、劫煞）与天月二德同柱，凶性会大大减弱——这是神煞组合运用的一个重要思路。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 寅午戌月生者见丙，申子辰月生者见壬，亥卯未月生者见甲，巳酉丑月生者见庚 |
| 作用 | 天月二德，其人恺悌慈祥，待人至诚仁厚。煞带天月德，明敏果决而仁厚；食伤带天月德，聪明秀慧而仁厚。二德以天德为重，月德次之 |

### 1.4 太极贵人

太极贵人主聪明好学、喜欢钻研深奥的学问。命带太极的人，对哲学、历史、宗教、玄学等科目往往有天然的亲近感。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 甲乙生人子午中，丙丁鸡兔定亨通，戊己两干临四季，庚辛寅亥禄丰隆，壬癸巳申偏喜美，值此应当福气钟 |
| 作用 | 主聪明好学，有钻劲，喜文史哲宗教等科目。为人正直，做事有始有终 |

### 1.5 文昌

文昌主文采和学业，命带文昌的人通常气质文雅、好学上进。考试运、学习运好的人，往往八字中带文昌星。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 甲乙巳午报君知，丙戊申宫丁己鸡。庚猪辛鼠壬逢虎，癸人见卯入云梯 |
| 查法 | 以年干或日干为主，四柱中地支所见者为是 |
| 作用 | 文昌入命，主聪明过人，逢凶化吉。气质雅秀，举止温文，好学新知，具上进心 |

### 1.6 天医

天医主健康和医术。命带天医且生旺的人，不仅自身身体好，还特别适合从事医疗、心理、养生等与健康相关的职业。

| 项目 | 内容 |
| --- | --- |
| 查法 | 正月生见丑，二月生见寅，三月生见卯，四月生见辰，五月生见巳，六月生见午，七月生见未，八月生见申，九月生见酉，十月生见戌，十一月生见亥，十二月生见子。以月支查其它地支 |
| 作用 | 生旺又有贵人相生助——身体健壮，特别适合医务工作及心理学、哲学等 |

## 二、中性神煞

中性神煞本身没有固定的吉凶，需结合具体命局判断。

### 2.1 驿马

驿马主走动、奔波、迁移。命带驿马的人天性好动，坐不住。商人、军人、外交官、销售等经常出差或调动工作的人，八字中往往带驿马星。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 申子辰马在寅，寅午戌马在申，巳酉丑马在亥，亥卯未马在巳 |
| 查法 | 以日支为主，四柱中临之则为马星 |
| 作用 | 马为走动、奔驰之象。主人好动，必有走遍东西南北之行。商人、军人、外交人员经常出差走动者多带马星 |

### 2.2 华盖

华盖是一颗孤独但有深度的星。命带华盖的人不爱热闹，喜欢独处思考，对哲学、宗教、玄学、艺术有天然的兴趣。很多学者、修行者、艺术家的八字中都带华盖。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 寅午戌见戌，亥卯未见未，申子辰见辰，巳酉丑见丑 |
| 查法 | 以年支或日支为主 |
| 作用 | 性情恬淡，雅洁高致，资质聪敏，富于文才与艺术性，倾向于哲学、宗教 |

### 2.3 将星

将星是权力之星，主组织领导能力。命带将星的人有慑众之威，适合担任管理职位。但要注意将星不能处于死绝或被冲破的状态，否则有名无实。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 寅午戌见午，巳酉丑见酉，申子辰见子，亥卯未见卯 |
| 查法 | 以年支或日支为主，四柱中地支所见者为是 |
| 作用 | 权力之星，具有组织领导指挥才能，有慑众之威。但死绝冲破者不利 |

### 2.4 桃花（咸池）

桃花主人缘和情缘，是大家最熟悉也最容易被误判的神煞。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 申子辰在酉，寅午戌在卯，巳酉丑在午，亥卯未在子 |
| 查法 | 以年支或日支查四柱其它地支 |
| 注意 | 桃花带羊刃，主多学多能，未免多疾。如见岁运逢冲桃花，会因色犯刑 |

### 2.5 禄神

禄神即十干临官之位，代表爵禄和福气。禄在年支为岁禄，月支为建禄，日支为专禄，时支为归禄——其中归禄（时柱）最为吉利，有"青云得路"之象。但禄忌落空亡或逢冲，称为"破禄"，反而主衣食不足。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 甲禄在寅，乙禄在卯，丙戊禄在巳，丁己禄在午，庚禄在申，辛禄在酉，壬禄在亥，癸禄在子 |
| 分类 | 年支→岁禄，月支→建禄，日支→专禄，时支→归禄 |
| 注意 | 禄落空亡或犯冲谓之破禄，贵人停职剥官，常人衣禄不足 |

### 2.6 魁罡

魁罡是特定的四个日柱——壬辰、庚戌、庚辰、戊戌。命带魁罡的人性格刚烈、正直果断、嫉恶如仇。但魁罡需要日主健旺才能发挥作用，日主弱的魁罡反而容易遭遇挫折。

| 项目 | 内容 |
| --- | --- |
| 四柱 | 壬辰、庚戌、庚辰、戊戌 |
| 条件 | 日柱见者为是，需日主健旺 |
| 性格 | 刚烈、正直、勇猛、个性耿直、胸无城府、嫉恶如仇、聪明果断、善用权力 |

### 2.7 羊刃（阳刃）

羊刃即阳干帝旺之位（甲卯、丙戊午、庚酉、壬子），是禄过则刃生的极限状态。羊刃刚烈暴戾，身强遇之是火上浇油，身弱有羊刃反而是帮身的好东西。如果天月二德同柱，可以化解羊刃的凶性。

| 项目 | 内容 |
| --- | --- |
| 查法 | 甲卯乙寅丙戊午，丁己巳庚酉辛申，壬子癸亥 |
| 特性 | 刚烈、暴戾、激发、急躁。禄过则刃生，功成当退不退 |
| 身强 | 不喜羊刃，有天月二德相助可以消灾 |
| 身弱 | 有羊刃可以助身 |

## 三、凶神类神煞

凶神类神煞代表阻碍、损失和不利因素。神煞仅供参考，不宜过度解读。

### 3.1 空亡

空亡是最特殊的一类凶神——它不是"坏"，而是"空"。求财见空亡，求之不得；求官见空亡，虚有其名。空亡落在不同的柱位，影响不同的亲缘领域。

| 项目 | 内容 |
| --- | --- |
| 查法 | 以日柱为主，柱中年月时支见者为空亡 |
| 含义 | 求之不得即为空亡 |

空亡落在不同柱位，对应不同人生面的"空了"。下面这张表帮你快速判断：

| 位置 | 信息 |
| --- | --- |
| 年支空亡 | 祖缘淡薄，祖辈有早故之人或祖业空；母空（辞世/改嫁/出走/母不顾子） |
| 月支空亡 | 家庭观念淡薄，无兄弟姐妹或兄弟姐妹无靠 |
| 时支空亡 | 不利子息，主无子女、子女多流产、夭折、身体欠佳 |

### 3.2 劫煞

劫煞代表外部力量对你财物的劫夺——"自外夺之谓之劫"。劫煞落在哪个柱位，那个柱位对应的人或事就容易被外人侵占、抢夺。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 申子辰见巳，亥卯未见申，寅午戌见亥，巳酉丑见寅 |
| 含义 | 劫者，夺也，自外夺之谓之劫。在十二长生诀中处绝地 |

### 3.3 亡神

亡神与劫煞相反——"自内失之谓之亡"。劫煞是外人来抢，亡神是自己内部出问题，比如决策失误、自己把机会搞砸。但如果亡神与吉神同柱，反而可能坏事变好事。

| 项目 | 内容 |
| --- | --- |
| 口诀 | 寅午戌见巳，亥卯未见寅，巳酉丑见申，申子辰见亥 |
| 含义 | 亡者，失也，自内失之谓之亡。劫在五行绝处，亡在五行旺处 |
| 注意 | "亡神入命祸非轻，算尽机关心不宁。"但与吉神同柱，反为好事 |

### 3.4 天罗地网

辰为天罗，戌为地网，男忌天罗，女忌地网。大运流年遇到天罗地网，容易有官司牢狱或严重的疾病灾祸，需要特别留意。

| 项目 | 内容 |
| --- | --- |
| 定义 | 辰为天罗，戌为地网。男忌天罗，女忌地网 |
| 作用 | 主疾病之灾，牢狱之灾，大运流年遇之，于人不利 |

### 3.5 阴阳差错

阴阳差错是十二个特定的日柱，主家庭关系不协调。女命带之容易与夫家相处不融洽，男命带之容易与妻家有是非。

| 项目 | 内容 |
| --- | --- |
| 查法 | 丙子、丁丑、戊寅、辛卯、壬辰、癸巳、丙午、丁未、戊申、辛酉、壬戌、癸亥十二日 |
| 女命 | 公姑寡合，妯娌不足，夫家冷退 |
| 男命 | 主退外家，与妻家是非寡合 |

### 3.6 孤鸾煞

孤鸾煞主孤独和婚姻不顺。查法是日柱和时柱同时出现孤鸾煞日中的任意两组，这比单神煞的判断要更谨慎一些——两个位置同时出现才构成孤鸾格。

| 项目 | 内容 |
| --- | --- |
| 查法 | 乙巳、丁巳、辛亥、戊申、壬寅、戊午、壬子、丙午。四柱日时同时出现以上任何两组者为是 |
| 含义 | 主孤独、不顺、克夫克妻 |

## 四、神煞运用的重要原则

### 4.1 《命理约言》的精辟论述

> "凡人命吉凶，皆由格局运气，安可偶合神煞而信之？" ——陈素庵《命理约言》
> 释义 ：人的命运吉凶，都是由格局和运气决定的，怎么可以偶然巧合神煞就相信呢？

### 4.2 对神煞的正确态度

- 主次分明 ：五行生克、十神关系与格局判定是命理学的主体
- 神煞为辅 ：神煞是神助的因素，仅作辅助参考，不可喧宾夺主，不宜过度解读

### 4.3 学习建议

- 五行生克 ：核心
- 十神关系 ：基石
- 格局判定 ：关键
- 神煞 ：神助因素，仅作辅助参考

## 本章小结

1. 吉神类神煞 - 天乙贵人（逢凶化吉）、天月二德（仁厚）、太极贵人（聪明好学）、文昌（聪慧）、天医（健康）
2. 中性神煞 - 驿马（走动）、华盖（哲学宗教）、将星（权力）、桃花（情感）、禄神（爵禄）、魁罡（刚烈）、羊刃（暴戾）
3. 凶神类神煞 - 空亡（求之不得）、劫煞（外夺）、亡神（内失）、天罗地网（牢狱）、阴阳差错（婚姻不顺）、孤鸾煞（孤独）
4. 核心原则 - 五行生克、十神关系为主，神煞为辅，不可喧宾夺主
