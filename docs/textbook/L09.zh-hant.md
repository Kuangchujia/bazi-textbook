## 十神類象入門：總述

**十神**，是八字命理學中用以表述”日干”與命局中其他七個干支之間生克、制化、親疏等關係的十個專用名詞。它們將干支間抽象的數理關係，轉化為具體的人事關係符號。

> **《三命通會》十神立名之本**：明萬民英《三命通會》云——”徐子平論格局，獨以印、食、官、財四者為綱。”以生克為基，以陰陽為別，立十神之名，開子平格局之先河。其立名之義：印綬者，蔭庇受福，如父母之恩德；食神者，如蟲食物，造化以子成而致養；官煞者，克身之物，官府以官與人，任其驅使；財星者，我克使用之物，如人成家立產，須得妻室內助。
> **經典四忌口訣**（《三命通會》）：明萬民英《三命通會·卷五·論古人立印食官財名義》云——”**官怕傷，被傷則禍；財怕劫，被劫則分；印怕財，貪財則壞；食怕梟，逢梟則奪。** 其理與人事無二，學者明於人事，斯可以言造化矣。”**《淵海子平·雜論口訣》**作異文：”官怕傷，財怕劫，印綬見財，愈多愈災……食衰梟旺，不死也災。”——此四句為十神喜忌之總綱。克我者各有天敵，旺而無制則成災——知其所怕，方能斷其安危。**其後緊接一句，即食神制殺之經典根據**：”夫五行展轉生克，皆子為父母復仇之義。”
> **⚠️ 鄺楚嘉校正（引文歸屬）**：舊本於此列”六忌口訣”六句，並冠以《淵海子平》之名，**實誤**。六句中”殺怕食，逢食則伏””傷怕印，見印則制”兩句，遍檢《淵海子平·雜論口訣》與《三命通會》均無此原文，乃後世據”食神制殺””印制傷官”之理推演而成，便於記誦而已。**其理不悖，其名不可託**——機理可用，但不可掛古籍之名。學者引用，當以四句為正、兩句為輔，並明言為輔。
> **一體多面公式**：**同一十神 × 不同維度 = 不同結論**。定維度→看力量→觀組合，三步法貫穿每個十神的類象分析。以下八個十神逐維展開。

#### 古典綱領

**順用逆用**（《子平真詮》）：”財官印食，此用神之善而順用之者也；煞傷劫刃，用神之不善而逆用之者也。當順而順，當逆而逆，配合得宜，皆為貴格。”——順用為扶，逆用為制，此即十神用法之總綱。

**十神凶格**（《三命通會》）：”傷官見官而早死，七煞見財夭亡，財逢劫盡死，重財破印凶，食神逢梟死於牢獄，劫重見財死，煞旺掛根休。”此七條為最凶組合，凡遇之須詳查有無制化。**凶格非絕路，有制化則凶中藏吉；吉神非坦途，無輔佐則福中轉禍。**

#### 十神·五組生克總綱

十神以日干為”我”，按生克關係分為五組。先明其類，再逐神展開。

| 關係 | 命名 | 象義 |
| --- | --- | --- |
| 生我者 | **印綬：** 印星+梟神 | 父母之義 |
| 同我者 | **比劫：** 比肩+劫財 | 兄弟之義 |
| 我生者 | **食傷：** 食神+傷官 | 兒女之義 |
| 我克者 | **財星：** 正財+偏財 | 妻財之義 |
| 克我者 | **官殺：** 正官+七殺 | 官鬼之義 |

#### 十神·一句話精要

在逐神展開之前，先用一張”速查卡”建立全局印象。下面每一句都濃縮了該十神最核心的特質與使用法則——讀完本節全貌後再回來對照，會有全新的理解。

| 十神 | 一句話精要 |
| --- | --- |
| **正官** | 榮身之本，克我以善——得財生印護則貴，被傷被合則禍。 |
| **七殺** | 攻身之煞，如抱虎眠——食制印化則為權，無制無化則為災。 |
| **正財** | 養命之源，穩定之財——身強能任則富，身弱逢之反為累。 |
| **偏財** | 意外之財，聚散無常——慷慨善交而得，揮霍難守而失。 |
| **正印** | 生身之母，蔭庇受福——護官制傷為文貴之基，被財所破則名利兩失。 |
| **偏印** | 偏門之智，獨闢蹊徑——見食則奪反目成梟，不見食神則同正印。 |
| **食神** | 壽星福星，制殺第一——溫和從容以才生財，被梟所奪福壽減損。 |
| **傷官** | 技藝之星，損官之患——聰明叛逆佩印則貴，傷盡見官為禍百端。 |
| **比肩** | 兄弟相助，分財分福——身弱得幫如雪中送炭，身旺成爭反為拖累。 |
| **劫財** | 奪財之首，凶過比肩——有制則團隊成事，無制則刀兵破財。 |

#### 克我者→官殺（正官+七殺）

> **《淵海子平》論偏官**：**“人有偏官，如抱虎而眠。雖借其威足以懾群畜，稍失關防，必為其噬臍。”** 有制伏則為偏官，無制伏則為七殺。

官殺是克制我、管束我的力量。正官為異性相克，如善意之管束；七殺為同性相克，如猛虎之威迫。正官順用（喜財生印護），七殺逆用（喜食神制伏）——同一組”克我”，陰陽不同則順逆殊途。

#### 我克者→財星（正財+偏財）

> **《淵海子平》論財星**：”財乃養命之源。”

財星是我所能掌控、支配之物。正財為穩定收入，偏財為意外之財。財宜有根有源，最怕比劫分奪。**官怕傷，財怕劫。**

#### 生我者→印綬（正印+偏印）

> **《淵海子平》論印綬**：”印綬者，蔭庇受福，如父母之恩德。”

印綬是生我、庇護我的力量。正印為慈母之愛（異性相生），偏印遇食神則反目為梟——同一組”生我”，見不見食神決定了是吉神還是凶神。**印怕財，食怕梟。**

#### 我生者→食傷（食神+傷官）

> **《淵海子平》論食神**：”食神者，如蟲食物，造化以子成而致養。”

食傷是我生發、創造的產物。食神溫和為福星（同性我生），傷官叛逆為技藝之星（異性我生）。食神制殺為權，傷官見官為禍——同一組”我生”，陰陽不同則一吉一凶。

#### 同我者→比劫（比肩+劫財）

> **《淵海子平》論比劫**：”比者，兄弟之義。”

比劫是與我同類、同氣相求的力量。比肩為同性相助，劫財為異性相爭。比劫幫身亦奪財——同一組”同我”，日主強弱不同則福禍相反。

## 一、正官類象

> 榮身之本，克我以善——得財生印護則貴，被傷被合則禍。正官，十神之首，榮身之本。八字的核心，就是維護一個良好狀態的正官。
> ** 《三命通會》論正官**：萬民英曰——”正官者，陰陽配合，相制有用，成其道也。故正官為六格之首，止許一位，多則不宜。”《淵源賦》云：”正官乃忠信尊重之名，治國齊家之號。”《萬祺賦》云：”官星者，榮身之主，掌祿之源，逢財則從容顯達，遇刃則偃蹇伶仃。”

### 1.1 基本定義

| 項目 | 內容 |
| --- | --- |
| **生克關係** | 異性克我者（陰陽相異，克制中帶有規範與善意） |
| **五行關係** | 如：甲木日干見辛金（陰金克陽木） |
| **核心職能** | 善意之管，如人民遵從政府與法律。八字以正官為榮身之本——代表社會地位、權利地位 |

### 1.2 多維類象

**正官精要**：正官幫助它，就會體現出正官好的一面；正官被破壞，則官非、壓力、小人隨之而來。

| 維度 | 正面 | 負面 / 注意事項 |
| --- | --- | --- |
| **性格特徵** | 傳統、穩重、有正義感，重視規範與法律 | 正官太過則愛慕虛榮，愛攀比且易受虛榮心所累（不管身旺身弱，官殺旺者虛榮心、攀比心皆強） |
| **人物類象** | 貴人、領導——正官得用，易得貴人幫助、領導賞識 | — |
| **六親類象** | 男命為子女（正財所生之故）；女命為丈夫 | 女命官殺過多，姻緣多半不順，易多婚；男命官殺過弱，子女緣分淺 |
| **事務類象** | 事業、職務、權力。官未被食傷損、未被合走者，可能在政界或事業單位工作 | 財生官旺者喜投資；官生印護者易得貴人提攜 |
| **性情類象** | 管理能力、把握機遇的能力 | 壓力、阻力、虛榮心 |
| **職業類象** | 行政管理類、創業類 | — |
| **健康類象** | 壓力系統（慢性壓力）、神經、外傷 | 官旺無制則長期高壓，易患慢性病 |
| **場所類象** | 政府機構、法院、行政機關 | — |
| **功能作用** | **衛財、生印、抑身、制劫** | 正官過旺則壓力過大，反為拘束 |

### 1.3 實戰判斷

| 狀態 | 判斷 | 原理 |
| --- | --- | --- |
| **正官得用** | 易得貴人幫助、領導賞識，事業順利 | 官有財生印護，格局清純 |
| **正官被傷** | 食傷損官，或被合走，不利事業 | 傷官見官，為禍百端 |
| **正官過旺** | 愛慕虛榮、愛攀比，壓力極大 | 官多為殺，善意之管變為惡意之壓 |

> **要點提醒**：正官是整個八字類象的總樞紐。看一個人能不能在社會上站住腳，先看正官——正官有沒有？在哪一柱？有沒有財來養？有沒有印來護？官清則命清，官亂則命亂。
> **《三命通會》正官核心法則**：<br> – **逢官看印**——正官格最喜行印鄉，印綬護官為第一要義。官無印則孤，印無官則虛。<br> – **官星重見，只作煞推**——正官多見則變殺，不再以吉神論，須制之為福。<br> – **時為歸息之地**——時辰可節制太盛之官，可補助漸衰之官，吉凶全在時消息。<br> – **五行官星各論**：金為官→職位清峻、刑獄決斷；木為官→品秩清高、守慎溫和；水為官→謙和得眾、循序升進；火為官→性烈用刑、發歇不常；土為官→穩重難犯、法令分明。
> **《三命通會》正官歌訣**<br> “正氣官星用月支，喜逢財印到年時。破害衝空俱不犯，富貴雙全報爾知。”<br> “官星大抵要身強，身弱須求氣旺方。印綬兼行財旺地，無衝傷破是榮昌。”<br> “正官大抵要純和，四柱無傷掇顯科。時上喜逢財健旺，柱中欣見印生多。”<br> 《相心賦》云：”官星愷悌，貴氣軒昂，抱優渥而仁慈寬大，懷豁達而聲韻和揚，丰姿美而秀麗，性格敏而聰明。”

## 二、七殺（偏官）類象

> 攻身之煞，如抱虎眠——食制印化則為權，無制無化則為災。七殺，古稱煞，凶神之首，專以攻身為要。有制謂之偏官，無制謂之七殺。制伏後則體現吉利的一面；若受到幫助，則體現出凶性。
> **《子平真詮》論偏官**：沈孝瞻曰——”煞以攻身，似非美物，而大貴之格，多存七煞。蓋控制得宜，煞為我用，如大英雄大豪傑，似難駕馭，而處之有方，則驚天動地之功，忽焉而就。此王侯將相所以多存七煞也。”又曰：”煞用食制者，上也，煞旺食強而身健，極為貴格。”

### 2.1 基本定義

| 項目 | 內容 |
| --- | --- |
| **生克關係** | 同性克我者（陰陽相同，克制猛烈如刀兵） |
| **五行關係** | 如：甲木日干見庚金（陽金克陽木） |
| **核心職能** | 攻身為要。煞者，敢想敢做、一往無前，決定後不計後果。為粗暴、衝動的象徵，容易因衝動導致違法犯罪 |

### 2.2 多維類象

| 維度 | 正面 | 負面 / 注意事項 |
| --- | --- | --- |
| **性格特徵** | 激烈、果斷、開拓進取、執行力強、有威嚴 | 好鬥、愛慕虛榮。財殺同時出現時：喜歡酒色而好鬥，容易和他人發生衝突，做事過度激進，為人自負，具有報復心，易入歧途。七殺過旺則愛慕虛榮、愛攀比且易受虛榮心所累 |
| **七殺旺而無制** | — | 身又弱者：無主見，膽小怕事，很容易受到刺激，性格抑鬱 |
| **人物類象** | 上司、武裝部隊、保安人員、警察等執法人員 | 小人、歹徒。七殺旺而無制，易遭受小人是非 |
| **六親類象** | 男命為子女，女命為情夫 | 女命財殺同時出現，七殺無食神制伏時，易遇渣男或易被家暴 |
| **事務類象** | 權力、武力 | 凶災、牢獄、糾紛、惡勢力、小人、敵人、災難、暴力、壓力、疾病、官司牢獄、刑事訴訟 |
| **性情類象** | 敢想敢做、一往無前 | 為忌則為手高眼低、有勇無謀。容易因衝動而導致違法犯罪 |
| **職業類象** | 高危職業、高風險職業、軍警法從業、行政管理（帶有執法性質） | 違法犯罪或擦邊球行為。七殺無制則容易是黑社會或是投機之人 |
| **健康類象** | 壓力系統（急性壓力）、外傷、疾病、精神緊張 | 殺旺攻身無制者，主傷殘、突發疾病 |
| **場所類象** | 監獄、公安機關、武裝部隊駐地 | — |
| **功能作用** | **護財、生印、攻身、制劫** | 七殺無制則攻身，主災禍 |

### 2.3 七殺有制與無制

| 狀態 | 名稱 | 表現 |
| --- | --- | --- |
| **有制**（食神傷官克制） | **偏官** | 凶性被制，轉化為正面力量——掌生殺之權，成威猛之才 |
| **無制** | **七殺** | 凶性大發，主災禍、壓力、疾病 |
| **旺而無制身又弱** | **七殺攻身** | 無主見，膽小怕事，易受刺激，性格抑鬱 |

> **要點提醒**：七殺如猛虎——看八字時第一反應不是”有七殺就凶”，而是”這個七殺有沒有被制住”。食神來制、印綬來化、傷官合煞，都是制煞的有效手段。古之豪傑，多有七殺——關鍵在於制化。
> **《三命通會》七殺制化三法**：<br> – **食神制殺**（硬手段）：**“一煞倡亂，獨力可擒。”** 單一七殺為禍，一位食神即可制伏——此為制殺第一法。<br> – **印綬化殺**（軟手段）：**“眾煞混行，一仁可化。”** 多殺混雜之時，一個印星（仁=印）即可化解——以德化暴，化敵為友。<br> – **傷官合殺**：傷官合殺，以智取勝，柔中帶剛。

## 三、正偏財類象

> 養命之源，身強能任——正財穩而偏財蕩，藏則不破露則分。財為養命之源，人人所欲，但非人人所得。財星不分偏正，皆為美物，統稱財星，一般以吉神論。
> ** 《子平真詮》論財**：沈孝瞻曰——”財為我克，使用之物也，以能生官，所以為美。為財帛，為妻妾，為才能，為驛馬，皆財類也。”又曰：”財喜根深，不宜太露。””身強而不透傷官，不混七煞，貴格也。”

### 3.1 正財與偏財的基本定義

| 項目 | 正財 | 偏財 |
| --- | --- | --- |

## 四、印綬類象

> 生身之母，蔭庇受福——正印為文貴之基，偏印見食則反目成梟。印綬，為權柄，又為父母生身之義，為一切有利於我的象徵。不分正印偏印，統稱印綬。正印一般為吉神；偏印遇食神則為凶神，稱梟神。
> ** 《子平真詮》論印綬**：沈孝瞻曰——”印綬喜其生身，正偏同為美格，故財與印不分偏正，同為一格而論之。”印綬之格局不一：有印而透官者，官星清純為貴；有印而用食傷泄秀者，身強印旺恐其太過，泄身以為秀氣；印多用財者，印重身強，透財以抑太過。

## 五、食神類象

> 壽星福星，制殺第一——以才生財溫和從容，被梟所奪福壽俱損。食神，七殺之天敵，專以制殺為要。故稱壽星——壽夭，往往看食神的狀態，一般以吉神論。
> ** 《子平真詮》論食神**：沈孝瞻曰——”食神本屬泄氣，以其能生正財，所以喜之。故食神生財，美格也。”食神之格不一：生財者身強食旺而財透，大貴；就煞印者最為威權顯赫；金水食神用煞，貴而且秀。又曰：”藏食露傷，主人性剛。”——食傷藏露之別，可斷人之剛柔。

## 六、傷官類象

> 技藝之星，損官之患——聰明叛逆佩印則貴，傷盡見官為禍百端。傷官，正官之天敵，專以損官為要。”傷官見官，為禍百端”，一般以凶神論。然傷官亦是技藝之星——制化得宜，則才華橫溢。
> ** 《子平真詮》論傷官**：沈孝瞻曰——”傷官雖非吉神，實為秀氣，故文人學士，多於傷官格內得之。而夏木見水，冬金見火，則又為秀之尤秀者也。”傷官格變化尤多——生財者轉凶為吉，佩印者制傷為貴，用官者金水獨宜。其要旨：”查其氣候，量其強弱，審其喜忌，觀其純雜，微之又微，不可執也。”

## 七、比肩類象

> 兄弟相助，亦分財福——身弱得幫為貴，身旺成爭為累。比肩，為兄弟之義，代表合作、分享、競爭、爭奪之意，不一定代表破財。日旺一般以凶神論，但不可一概而論。
> **《子平真詮》論建祿月劫**：沈孝瞻曰——”建祿者，月建逢祿堂也，祿即是劫。故建祿與月劫，可同一格，不必加分，皆以透干支，別取財官煞食為用。”祿劫格需另取財官為用——祿劫用官，喜財印相隨，不可孤官無輔；祿劫用財，須帶食傷以化劫生財；祿劫用煞，必須制伏。又曰：”祿劫之格，無財官而用傷食，泄其太過，亦為秀氣。唯春木秋金，用之則貴，蓋木逢火則明，金生水則靈。”

### 7.1 基本定義

| 項目 | 內容 |
| --- | --- |
| **生克關係** | 同性同我者（陰陽相同） |
| **五行關係** | 如：甲木日干見甲木（同陽木） |
| **核心職能** | 奪財分福。日旺一般以凶神論——但比肩亦代表合作與助力，不可一概而論 |

### 7.2 多維類象

**比肩總綱**：比肩為兄弟之義，代表社交關係與團隊力量。比劫代表人氣和下屬——很多大企業家都有比劫旺相的信息，因比劫代表手足、員工、職員，沒有比劫反而很難成事。但比肩太旺，也代表容易因經濟糾紛影響合作關係。

| 維度 | 正面 | 負面 / 注意事項 |
| --- | --- | --- |
| **性格特徵** | 自信自尊，意志堅定，為人友善，善於結交朋友，有主見 | 剛愎自用、好勝攀比，有爭奪之心，疑心重 |
| **人物類象** | 貴人、給予自己幫助之人、秘書、助理、團隊、合作夥伴 | 競爭對手、情敵、小人 |
| **六親類象** | 兄弟、姐妹、同輩、朋友、同事 | 比肩太旺易因經濟糾紛影響合作關係 |
| **事務類象** | 社交關係、團隊協作、合作合夥 | 競爭爭奪、經濟糾紛 |
| **性情類象** | 有主見、有擔當、果斷、大膽，善於社交 | 疑心重，好勝攀比 |
| **職業類象** | 合夥事業、團隊型事業、利用人際關係之事業（商業、中介、銷售）；軍警法等高危職業；重勞力性工作（如工廠流水線）；激烈的工作（如運動員） | 比肩過旺則合作易散，團隊難久 |
| **健康類象** | 手足、四肢、運動系統、自我修復能力 | 比肩被沖克易骨折、肌肉損傷 |
| **場所類象** | 競技場、體育場、健身房、工廠車間 | — |
| **功能作用** | **敵官殺、幫身、奪財**——對抗官殺、幫助自身、爭奪財富 | 比劫奪財則破財 |

### 7.3 實戰判斷

| 狀態 | 判斷 | 原理 |
| --- | --- | --- |
| **比肩得用** | 朋友多、人緣好，團隊合作順利，有人幫襯 | 比肩為助力，幫身抗殺 |
| **比肩為忌** | 兄弟分財，合夥破財，被朋友拖累 | 比劫奪財 |
| **比肩旺而身強** | 剛愎自用，好勝攀比，競爭激烈 | 身旺不勞比助，反成爭奪 |
| **比肩旺而身弱** | 得朋友兄弟之力，合作成事 | 比肩幫身，雪中送炭 |
| **比肩敵官殺** | 團隊對抗壓力，眾人拾柴火焰高 | 比肩聯合以抗官殺 |

> **要點提醒**：比肩是十神中”最看身旺身弱”的一顆星。身旺見比肩如錦上添花——花多了反而亂；身弱見比肩如雪中送炭——炭多了卻能取暖。看比肩第二問：比肩旁邊有沒有財星？比劫奪財是斷破財的第一信號，但若有官殺制比護財，反成團隊協作生財之象。第三問：比肩在哪一柱？年上比肩祖上有兄弟，月上比肩兄弟姐妹多，日上比肩夫妻有競爭，時上比肩子女朋友多——位置定親疏。大企業家多有比劫旺相，不是因為他們命好有比劫，而是比劫代表員工、下屬——沒有比劫，一個人做不了大事。

## 八、劫財類象

> 奪財之首，凶過比肩——有制則團隊成事，無制則刀兵破財。劫財，財星天敵，專以奪財為要，即搶劫奪財之義，故又稱”逐馬”。日旺一般以凶神論，但不可一概而論。
> ** 《子平真詮》論陽刃**（陽刃即劫財之甚者）：沈孝瞻曰——”陽刃者，劫我正財之神，乃正財之七煞也。祿前一位，惟五陽有之，故為陽刃。不曰劫而曰刃，劫之甚也。刃宜伏制，官煞皆宜，財印相隨，尤為貴顯。”陽刃用官，透刃不慮——官能制刃；陽刃露煞，透刃無成——刃能合煞則無功。陽刃用財，格所不喜，然財根深而用傷食以轉刃生財，亦可就富。

### 8.1 基本定義

| 項目 | 內容 |
| --- | --- |
| **生克關係** | 異性同我者（陰陽不同） |
| **五行關係** | 如：甲木日干見乙木（陽木見陰木） |
| **核心職能** | 財星天敵，專以奪財為要。劫財奪財奪福奪命，奪掉一切可奪之物 |

### 8.2 多維類象

**劫財總綱**：劫財即是搶劫奪財之義，故又稱”逐馬”。經云：”無財遇劫，縱非財年，亦須見破”——可見劫財奪財之凶狠。劫財通常代表兵刃、刀槍、手術、災禍。若劫財再遇傷官，稱作”背祿逐馬”，《珞琭子》云：”背祿逐馬，守窮途而悽惶”。馬是貴氣、官星、祿財星——劫財傷官並見，財官俱損。

| 維度 | 正面 | 負面 / 注意事項 |
| --- | --- | --- |
| **性格特徵** | 有主見、有擔當、果斷、大膽 | 沖動、好鬥、疑心重 |
| **人物類象** | 貴人、秘書、助理、團隊、合作夥伴 | 盜竊團夥、小人 |
| **六親類象** | 兄弟、姐妹（異性）、朋友、同事 | 劫財旺者克妻或與妻子關係不好 |
| **事務類象** | 社交關係、團隊協作 | 兵刃、刀槍、手術、災禍、奪財奪福 |
| **性情類象** | 有主見、有擔當、果斷、大膽，善社交 | 沖動好鬥，疑心重，奪心強 |
| **職業類象** | 合夥事業、團體型事業、利用人際關係之事業（商業、中介、銷售）；軍警法等高危職業；重勞力性工作（如工廠流水線）；激烈的工作（如運動員） | 劫財無制則易入盜竊團夥、黑社會 |

| **功能作用** | **敵官殺、幫身、奪財**——對抗官殺、幫助自身、爭奪財富 | 劫財奪財比肩更凶狠；劫財再遇傷官則”背祿逐馬”，窮途而悽惶 |

### 8.3 實戰判斷

| 狀態 | 判斷 | 原理 |
| --- | --- | --- |
| **劫財得用** | 果斷敢為，團隊有威，抗官殺得力 | 劫財幫身，化凶為用 |
| **劫財奪財** | 破財——經云”無財遇劫，縱非財年，亦須見破” | 劫財克財，奪財奪福 |
| **劫財遇傷官** | 背祿逐馬——財官俱損，窮途而悽惶 | 劫財奪財+傷官損官 |
| **劫財旺而無制** | 沖動好鬥，易入歧途，克妻損財 | 凶神無制 |
| **劫財有官殺制** | 官殺制劫護財，轉凶為吉，團隊成事 | 以官制劫，化奪為助 |

> **要點提醒**：劫財與比肩同屬”幫身奪財”類，但劫財奪財更凶狠——比肩是”分財”，劫財是”奪財”。分財尚有商量，奪財毫無餘地。經云”無財遇劫，縱非財年，亦須見破”，足見其凶。看劫財三問：一、身邊有沒有財星？有財則奪，無財則暫無大礙。二、有沒有官殺制劫護財？官殺可制劫護財，轉凶為吉。三、劫財遇沒遇到傷官？劫財遇傷官是”背祿逐馬”——財星被劫、官星被傷，錢財地位雙失，是大凶組合。另外，劫財也代表兵刃手術——流年遇劫財被沖克者，宜防意外傷災。
> **《三命通會》比劫核心法則**：<br> – **權刃復行權刃，刀藥亡身**——權力（官殺）與羊刃（劫財）重疊，再逢權刃大運，有刀兵毒藥之災。此為劫財最凶之應——**劫刃疊見，身旺無制，必見血光。**<br> – **兄弟破財財得用**——比肩雖奪財，但財反能為己所用（團隊生財之象）。**比劫非必奪財，要看身旺身弱：身弱得比劫幫身，反是貴人。**<br> – **夫妻隨娶隨傷，蓋為比肩伏馬**——比肩暗伏於妻財之下，婚姻反覆多變。男命比劫重者，須防婚變。

## 五大經典矛盾

> 通讀八神類象之後，將這五組矛盾置於全局視野下重新審視——每一條”怕”背後都有化解之道，每一個凶格之中都藏著權柄之門。以下綜合全課內容，逐一詳解。

**梟印奪食**（偏印制食神）——最為凶險。

偏印見食神而反目為梟，福神被克則三層能力盡失：思想能力（喪失靈感與表達）、掙錢能力（食不生財則財源斷裂）、抵禦災病的免疫力（食不制殺則殺來攻身）。食神逢刑沖克奪，輕者才華受抑、思想枯竭，重者意外傷災、官非訴訟甚至牢獄之災。女命旺印克食傷，主不孕、流產、子女緣薄。食神太旺而無財者，雖未被奪，亦多自私小氣——此為本課食神章的補充要點。化解之法：用財壞印護食——梟食對峙之時，引入財星則梟轉而去克財，食神得救。此為財破印護食之通路。

**比劫奪財**（比劫克財星）——最為常見。

財為養命之源、男命之妻星。比劫分奪，夥伴分財，易破財、合夥受損；男命婚姻困難或婚變。劫財代表兵刃、刀槍、手術、災禍——”劫財奪財奪福奪命，奪掉一切可奪之物”。劫財若再遇傷官，則稱”背祿逐馬”，《珞琭子》云”背祿逐馬，守窮途而悽惶”。比肩雖亦奪財，但也代表合作、分享、競爭，不一定即破財——此為本課比肩章的核心提示：身弱得比劫幫身，反是貴人。化解路徑：食傷化比劫而生財，或官星制比劫而護財。比劫奪財的終極判斷在於日主強弱——身強奪財是災，身弱得幫是福。

**食神制殺**（食神制七殺）——化凶為吉。

七殺為凶神之首，攻身則主傷殘、疾病、牢獄，如抱虎而眠。食神為七殺之天敵，專以制殺為要，使日干安然無患，故食神又稱”壽星”。壽夭往往看食神的狀態——此為本課食神章第一要義。命局有食神制殺者，遇凶險亦能化險為夷，反為權柄福氣。食神用煞者，宜軍警法、執法屬性或行政管理、創業經商。女命以食神為福星，食神制殺有力，不僅自身平安，亦能旺夫益子。

**傷官見官**（傷官克正官）——為禍百端。

正官為十神之首、榮身之本，傷官仗勢欺人、放任日干於理法之外。二者力量相當時禍事不斷，主犯官司、是非、小人，事業多變，人際關係緊張。但傷官亦有另一面——代表思維、天賦、靈感、藝術才華，不循正規、不按常理出牌、喜歡走捷徑。古云”五制傷官，為禍百端；利物傷官，聰明異端”——此為本課傷官章的核心辯證。化解路徑：傷官務要傷盡——傷之不盡，官來乘旺，其禍不可勝言。佩印則以印制傷（靠學問修養約束才華），生財則以財化傷（將叛逆轉化為商業價值），此為兩條化解大道。

**財壞印**（財星克印綬）——因利失義。

印為名聲、學業、母親，代表保守、守舊、按部就班、有利於學業但欠缺靈活。財為創新、變通、現實利益、藝術氣質、享受生活。財印是一組天生矛盾——財旺克印之人，有經濟頭腦但無心向學，”財多不是讀書人”；印旺無財之人，博學清高但不善營生。正財旺者克母，與母親緣薄——此為本課印綬章與財星章的交叉要點。化解路徑：官星通關——財生官、官生印，財不壞印反成官印相生之貴格。此為五行通關之法在十神層面的最佳範例。

> **五組矛盾總覽**：
> 梟印奪食最凶（福神被克），食神制殺最吉（凶神被制），比劫奪財最常見（每日可見）。化解之道藏於生克規律之中——**梟印奪食，用財壞印護食；比劫奪財，以食傷化之或官星護之；食神制殺，以食為帥；傷官見官，以印為枷、以財為渠；財壞印，以官為橋。** 初學者先記”梟印奪食、食神制殺、比劫奪財”三組，其餘在實踐中逐步掌握。進階課程中，十神組合三部曲（第10-12課）將逐一詳解化解之道。

## 本章小結

1. **正官** – 異性克我，溫情約束，主正義負責；女命夫星，男命子女
2. **七殺** – 同性克我，嚴厲克制，主果斷霸道；有制為偏官，無制為七殺
3. **正偏財** – 養命之源，不分偏正。正財主穩定收入，偏財主意外之財；男命正財為妻、偏財為情人；不分男女偏財為父
4. **印綬** – 生我權柄，不分偏正。正印主正統學識，偏印主偏門玄學；見食神為梟神奪食
5. **食神** – 同性我生，溫和才藝，主樂觀知趣；壽星，七殺天敵；女命女兒；不分男女為祖輩
6. **傷官** – 異性我生，叛逆才華，主聰明桀驁；正官天敵；女命兒子
7. **比肩** – 同性同我，合作競爭，主自信有主見；兄弟朋友；幫身亦奪財，旺弱定吉凶
8. **劫財** – 異性同我，爭奪搶奪，主衝動好鬥；財星天敵，奪財奪福奪命，又稱”逐馬”；遇傷官則背祿逐馬
9. **五大經典矛盾** – 梟印奪食（最凶）、比劫奪財（最常見）、食神制殺（最吉）、傷官見官、財壞印——化解之道藏於生克規律之中
