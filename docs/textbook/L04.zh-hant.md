## 一、地支的五行屬性及陰陽屬性

地支十二，分為三類——寅申巳亥為四生（長生之地），子午卯酉為四正（帝旺之地），辰戌丑未為四庫（墓庫之地）。明此三類，地支過半矣。

### 1.1 十二地支序列

**十二地支的順序：** 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥。

子鼠、丑牛、寅虎、卯兔、辰龍、巳蛇、午馬、未羊、申猴、酉雞、戌狗、亥豬。

### 1.2 地支的陰陽與五行

**地支的陰陽**（與天干相同，奇數為陽，偶數為陰）：子寅辰午申戌為陽支，丑卯巳未酉亥為陰支。

**地支的五行屬性：**

寅卯辰屬木（寅陽木、卯陰木），巳午未屬火（巳陽火、午陰火），申酉戌屬金（申陽金、酉陰金），亥子丑屬水（亥陽水、子陰水），辰戌丑未又屬土（四季土）。

> **實戰意義** ：地支的五行屬性不像天干那麼”純”，很多地支是”雜氣”——既有主氣，又有餘氣。這就是地支比天干複雜的地方！

## 二、地支與四季、方位、時辰

**《淵海子平》論月令用事**：

> “立春戊丙各七朝，一十四日甲木交。驚蟄甲木旺一旬，餘下乙木有對沖。”

每月之中，五行之氣並非均勻分布——以正月（寅月）為例，立春後前七日戊土司令，再七日丙火司令，後十四日甲木當權。這就是地支藏干中”寅藏甲丙戊”的由來：寅月雖為木月，但初春寒氣未退，戊土、丙火先行為木開路。明此理，方知地支藏干並非隨意排列，而是依節氣流轉依次交接。

> ⚠ **存疑標記（2026-09-18 · 正文未改）**：《淵海子平·又論節氣歌》通行文本作「**十六**甲木方堪器」（後十六日甲木用事，7＋7＋16＝30）；本句作「後**十四**日甲木當權」（7＋7＋14＝28，與寅月三十日不合）。**兩說並存，正文照舊，待考。**

### 2.1 地支與四季、方位

少陽木（寅卯辰），司春，主東方。太陽火（巳午未），司夏，主南方。少陰金（申酉戌），司秋，主西方。太陰水（亥子丑），司冬，主北方。

> **原文**：少陽木見於寅，壯於卯，衰於辰。太陽火見於巳，壯於午，衰於未。少陰金見於申，壯於酉，衰於戌。太陰水見於亥，壯於子，衰於丑。
> 此段描述的是**五行之氣在十二個月中流轉的狀態**——每行入季時初現（見），至仲月達到頂峰（壯），季末走向衰微（衰）。以木為例：寅月木氣初現，卯月木氣最旺，辰月木氣衰退、土氣當令。

### 2.2 地支與時辰

古人將一天二十四小時劃分為十二個時辰，每個時辰兩小時：

子時（23:00-01:00 夜半）<br> 丑時（01:00-03:00 雞鳴）<br> 寅時（03:00-05:00 平旦）<br> 卯時（05:00-07:00 日出）<br> 辰時（07:00-09:00 食時）<br> 巳時（09:00-11:00 隅中）<br> 午時（11:00-13:00 日中）<br> 未時（13:00-15:00 日昳）<br> 申時（15:00-17:00 晡時）<br> 酉時（17:00-19:00 日入）<br> 戌時（19:00-21:00 黃昏）<br> 亥時（21:00-23:00 人定）

## 三、四孟、四正、四庫

地支十二，按位置和節氣分為三類：

**四孟**（四季開端）——寅（東北·正月）、巳（東南·四月）、申（西南·七月）、亥（西北·十月）。寅申巳亥為四生之地。

**四正**（四正方）——子（正北·十一月）、卯（正東·二月）、午（正南·五月）、酉（正西·八月）。子午卯酉為四帝旺之地。

**四庫**（四季末）——辰（東南·三月）、未（西南·六月）、戌（西北·九月）、丑（東北·十二月）。辰戌丑未為四墓庫之地。

> **《四言獨步》**：”寅申巳亥，四生之局；用物身強，遇之發福。辰戌丑未，四庫之神；人元三用，透旺為真。”

> **鄺楚嘉按**：六十甲子是八字排盤的”九九乘法表”。初學時不用全部背下來，但甲子、甲戌、甲申、甲午、甲辰、甲寅這六個旬首必須爛熟——因為空亡從旬首推出，旬首記不住，空亡永遠找不到。每天背一旬，六天背完，一生受用。

## 五、地支藏干

### 5.1 天地人三元

八字命理學中，天干為**天元**，代表外在的、顯露的能量；地支為**地元**，代表承載的、根基的力量；地支中所藏的天干為**人元**，代表內在的、潛伏的氣質。天地人三元同出一柱，構成了八字分析的三個層次——看天干知外在表現，看地支知根基深淺，看藏干知暗藏玄機。

```
十二地支除子午卯酉較純外，其餘均藏二至三個天干，這便有了"雜氣"之說。以寅為例：寅為木，但中藏甲木（本氣）、丙火（中氣）、戊土（餘氣）——寅不僅是木，還暗含火與土的力量。這正是地支比天干複雜的原因。
```

### 5.3 藏干規律

**四正（子午卯酉）：** 為本氣獨藏或精氣所在。

- 子：癸（純水）
- 卯：乙（純木）
- 午：丁己（火為主）
- 酉：辛（純金）

**四孟（寅申巳亥）：** 主氣旺→生中氣→中氣生餘氣（五行相生規律）。

- 寅：甲（木旺生火）→丙（火旺生土）→戊；**寅藏：甲丙戊**
- 巳：丙（火旺生土）→戊（土旺生金）→庚；**巳藏：丙戊庚**
- 申：庚（金旺生水）→壬（水土共存）→戊；**申藏：庚壬戊**
- 亥：壬（水旺生木）→甲；**亥藏：壬甲**

**四維/四隅（辰戌丑未）：** 以土為主氣，居中為季節轉換之氣。

- 辰：戊（春末）→乙（水庫）→癸；**辰藏：戊乙癸**
- 未：己（夏末）→丁（木庫）→乙；**未藏：己丁乙**
- 戌：戊（秋末）→辛（火庫）→丁；**戌藏：戊辛丁**
- 丑：己（冬末）→癸（金庫）→辛；**丑藏：己癸辛**

> ⚠ **存疑標記（2026-09-18 · 正文未改）**：上列四處括號中的「某庫」均掛在**第二位**（辰之乙、未之丁、戌之辛、丑之癸）；而按三支所藏**末位**之干（辰之癸、水；未之乙、木；戌之丁、火；丑之辛、金）才是該「庫」所系之五行。**四處位置各差一位，正文照舊，待考。**

### 5.4 記憶歌訣

> 子藏癸水在其中，丑中癸辛己土同。寅藏甲木和丙戊，卯中乙木獨相逢。<br> 辰藏乙木兼戊癸，巳中庚金有丙戊。午藏丁火併己土，未中乙木加己丁。<br> 申藏戊土庚並壬，酉中辛金獨豐隆。戌藏辛金及丁戊，亥中壬甲是真蹤。
> **鄺楚嘉按**：藏干是八字最難背也最重要的基礎之一。我的經驗——先背四孟（寅申巳亥）的生克規律，再背四正（子午卯酉）的獨藏，四庫（辰戌丑未）最後記。每天默寫一遍，一周後就能條件反射。記住：見地支不看藏干，等於看人只看外表不看內心。

## 六、地支生克

地支之間的生克原理與五行生克相同，但由於地支含藏干，比天干生克更複雜——寅不僅是木，還藏著火和土；子雖是水，但藏癸純水。同樣”水生木”，子水生寅木與亥水生卯木的效果並不完全一樣。

**相生**（順位）：寅卯木生巳午火 → 巳午火生辰戌丑未土 → 辰戌丑未土生申酉金 → 申酉金生亥子水 → 亥子水生寅卯木。

**相克**（隔位）：寅卯木克辰戌丑未土 → 辰戌丑未土克亥子水 → 亥子水克巳午火 → 巳午火克申酉金 → 申酉金克寅卯木。

> 地支生克的核心不在字面，在藏干——看哪個藏干在互動，才是真正看懂地支生克的關鍵。
