# 第9課 十神類象

[简体中文](/textbook/L09/) ｜ [繁體中文](/zh-hant/textbook/L09/) ｜ [English](/en/textbook/L09/) ｜ **日本語** ｜ [한국어](/ko/textbook/L09/)

## 十神類象入門：総述

十神とは、八字命理学において「日干」と命局の他の七つの干支とのあいだの生剋・制化・親疎などの関係を表す十の専門用語である。干支間の抽象的な数理関係を、具体的な人事関係の符号へと転換するものである。

『三命通会』十神立名の本——明の万民英『三命通会』に云う、「徐子平論格局，獨以印、食、官、財四者為綱」。生剋を基とし、陰陽を別とし、十神の名を立てて子平格局の先駆けを開いた。その立名の義は次のとおりである。印綬（YinShou）は蔭庇受福、すなわち父母の恩徳のごときもの。食神（ShiShen）は虫の物を食うがごとく、造化が子を成して養いを致すがごときもの。官殺（GuanSha）は身を剋する物、官府が官を人に与えてその駆使に任せるがごときもの。財星（CaiXing）は我が剋して使用する物、人が家を成し産を立てるには妻室の内助を得るがごときもの。

経典の四忌口訣（『三命通会』）——明の万民英『三命通会』巻五「古人立印食官財名義論」に云う。以下がそれである。

> 

この四句が十神の喜忌の総綱である。我を剋する者にはそれぞれ天敵があり、旺じて制なければ災となる。その怕れるところを知ってこそ、その安危を断じうる。『淵海子平・雑論口訣』は異文を作す——「官怕傷，財怕劫，印綬見財，愈多愈災……食衰梟旺，不死也災」。そのすぐ後に続く一句が、食神制殺の古典的な根拠である——「夫五行展轉生剋，皆子為父母復仇之義」。

⚠️ 邝楚嘉校正（引文の帰属）：旧本はここに「六忌口訣」の六句を列し、『淵海子平』の名を冠しているが、実は誤りである。六句のうち「殺怕食，逢食則伏」「傷怕印，見印則制」の二句は、『淵海子平・雑論口訣』と『三命通会』のいずれを遍く検しても原文がなく、後世が「食神制殺」「印制傷官」の理によって推演し、記誦に便ならしめたものにすぎない。その理は悖らず、その名は託すべからず——機序は用いてよいが、古籍の名を掛けてはならない。学者が引用するときは、四句を正とし、二句を補とし、補であると明言すべきである。

一体多面の公式：同一の十神 × 異なる次元 ＝ 異なる結論。次元を定め→力量を見→組合せを観る、この三步法が各十神の類象分析を貫く。以下の八つの十神を次元ごとに展開する。

#### 古典綱領

順用と逆用（『子平真詮』）——「財官印食，此用神之善而順用之者也；煞傷劫刃，用神之不善而逆用之者也。當順而順，當逆而逆，配合得宜，皆為貴格」。順用は扶、逆用は制——これが十神用法の総綱である。

十神の凶格（『三命通会』）——「傷官見官而早死，七煞見財夭亡，財逢劫盡死，重財破印凶，食神逢梟死於牢獄，劫重見財死，煞旺掛根休」。この七条は最も凶なる組合せであり、遇うときは必ず制化の有無を詳査する。凶格は絶路に非ず、制化あれば凶中に吉を蔵す。吉神は坦途に非ず、輔佐なければ福中に禍を転ずる。

#### 十神・五組生剋総綱

十神は日干を「我」とし、生剋関係によって五組に分かつ。まずその類を明らかにし、次いで神ごとに展開する。

| 関係 | 命名 | 象義 |
| --- | --- | --- |
| 生我者 | 印綬：印星＋梟神 | 父母の義 |
| 同我者 | 比劫（BiJie）：比肩＋劫財 | 兄弟の義 |
| 我生者 | 食傷（ShiShang）：食神＋傷官 | 児女の義 |
| 我克者 | 財星：正財＋偏財 | 妻財の義 |
| 克我者 | 官殺：正官＋七殺 | 官鬼の義 |

#### 十神・一句精要

神ごとの展開に入る前に、まず一枚の「速査カード」で全体像をつかむ。以下の各句はいずれも、その十神の最も核心的な特質と用法を濃縮したものである——本節を通読した後で戻って照らし合わせれば、まったく新しい理解が得られる。

| 十神 | 一句精要 |
| --- | --- |
| 正官（ZhengGuan） | 栄身の本、我を剋するに善を以てす——財の生と印の護りを得れば貴、傷められ合わされば禍。 |
| 七殺（QiSha） | 攻身の煞、虎を抱いて眠るがごとし——食の制と印の化あれば権、制なく化なければ災。 |
| 正財（ZhengCai） | 養命の源、安定の財——身強くして任じ得れば富、身弱くして之に逢えば反って累となる。 |
| 偏財（PianCai） | 意外の財、聚散常なし——気前よく交わって得、散財して守り難く、失う。 |
| 正印（ZhengYin） | 生身の母、蔭庇受福——官を護り傷を制するは文貴の基、財に破らるれば名も利も両失す。 |
| 偏印（PianYin） | 偏門の智、独り蹊径を開く——食を見れば奪いて反目し梟と成り、食神を見ざれば正印に同じ。 |
| 食神 | 寿星福星、制殺第一——温和従容として才能を以て財を生じ、梟に奪わるれば福壽減損す。 |
| 傷官（ShangGuan） | 技芸の星、損官の患——聡明叛逆、印を佩れば貴、傷尽きて官を見れば禍百端。 |
| 比肩（BiJian） | 兄弟相助け、財を分かち福を分かつ——身弱くして助けを得れば雪中に炭を送るのごとく、身旺にして争いを成せば反って足手まといとなる。 |
| 劫財（JieCai） | 奪財の首、凶なること比肩に過ぐ——制あればチーム事を成し、制なきは刀兵財を破る。 |

#### 克我者→官殺（正官＋七殺）

『淵海子平』偏官を論ず——「人有偏官，如抱虎而眠。雖借其威足以懾群畜，稍失關防，必為其噬臍」。制伏あれば偏官と為し、制伏なければ七殺と為す。

官殺は我を剋し、我を管束する力量である。正官は異性の相剋で、善意の管束のごとく、七殺は同性の相剋で、猛虎の威迫のごとくである。正官は順用（財の生と印の護りを喜ぶ）、七殺は逆用（食神の制伏を喜ぶ）——同じ「克我」の一組でも、陰陽が異なれば順逆は別の途を辿る。

#### 我克者→財星（正財＋偏財）

『淵海子平』財星を論ず——「財乃養命之源」。

財星は我が掌控・支配しうる物である。正財は安定した収入、偏財は意外の財。財は根あり源あるを宜しとし、最も比劫の分奪を怕れる。官は傷を怕れ、財は劫を怕れる。

#### 生我者→印綬（正印＋偏印）

『淵海子平』印綬を論ず——「印綬者，蔭庇受福，如父母之恩德」。

印綬は我を生じ、我を庇護する力量である。正印は慈母の愛（異性の相生）、偏印は食神に遇えば反目して梟となる——同じ「生我」の一組でも、食神を見るか見ざるかが吉神か凶神かを決める。印は財を怕れ、食は梟を怕れる。

#### 我生者→食傷（食神＋傷官）

『淵海子平』食神を論ず——「食神者，如蟲食物，造化以子成而致養」。

食傷は我が生発・創造する産物である。食神は温和にして福星（同性の我生）、傷官は叛逆にして技芸の星（異性の我生）。食神制殺は権、傷官見官は禍——同じ「我生」の一組でも、陰陽が異なれば一は吉、一は凶となる。

#### 同我者→比劫（比肩＋劫財）

『淵海子平』比劫を論ず——「比者，兄弟之義」。

比劫は我と同類・同気相求の力量である。比肩は同性の相助、劫財は異性の相争。比劫は身を助けまた財を奪う——同じ「同我」の一組でも、日主の強弱によって福禍は相反する。

## 一、正官類象

栄身の本、我を剋するに善を以てす——財の生と印の護りを得れば貴、傷められ合わされば禍。正官は十神の首、栄身の本である。八字の中核は、良好な状態の正官を維持することにある。

『三命通会』正官を論ず——万民英曰く、正官とは陰陽が配合し、相制して用をなし、その道を成すものである。ゆえに正官は六格の首であり、ただ一位を許し、多きは宜しからず。『淵源賦』は「忠信尊重之名，治國齊家之號」と称し、『万祺賦』は官星を栄身の主・掌禄の源とし、財に逢えば従容として顕達し、刃に遇えば偃蹇伶仃となると述べる。

> 

### 1.1 基本定義

| 項目 | 内容 |
| --- | --- |
| 生剋関係 | 異性の我を剋する者（陰陽相異なり、剋制の中に規範と善意を帯びる） |
| 五行関係 | 例えば、甲木の日干が辛金を見る（陰金が陽木を剋す） |
| 核心職能 | 善意の管、人民が政府と法律に従うがごとし。八字は正官を栄身の本とする——社会地位・権利地位を表す |

### 1.2 多次元類象

正官精要：正官を助ければ、正官の善き面が現れる。正官が破られれば、官非・圧力・小人がこれに伴って来る。

| 次元 | 正面 | 負面／注意事項 |
| --- | --- | --- |
| 性格特徴 | 伝統的で落ち着きがあり、正義感があり、規範と法律を重んじる | 正官が過ぎれば虚栄を愛し、張り合いを好み、虚栄心に苦しめられやすい（身旺・身弱を問わず、官殺の旺ずる者は虚栄心・張り合いの心がいずれも強い） |
| 人物類象 | 貴人、上長——正官が用を得れば、貴人の助け・上長の知遇を得やすい | — |
| 六親類象 | 男命は子女（正財の生ずるところによる）；女命は夫 | 女命は官殺が多すぎれば縁談はおおむね順調ならず、多婚しやすい；男命は官殺が弱すぎれば子女の縁が浅い |
| 事務類象 | 事業、職務、権力。官が食傷に損なわれず、合い去られてもいない者は、政界や公共機関で働く可能性がある | 財が官を生じて旺ずる者は投資を好む；官が印を生じて護る者は貴人の提携を得やすい |
| 性情類象 | 管理能力、機会を捉える能力 | プレッシャー、妨げ、虚栄心 |
| 職業類象 | 行政管理類、創業類 | — |
| 健康類象 | 圧力系統（慢性の圧力）、神経、外傷 | 官が旺じて制なければ長期の高圧となり、慢性病を患いやすい |
| 場所類象 | 政府機関、裁判所、行政機関 | — |
| 功能作用 | 衛財、生印、抑身、制劫 | 正官が旺じすぎれば圧力が過大となり、反って拘束となる |

### 1.3 実戦判断

| 状態 | 判断 | 原理 |
| --- | --- | --- |
| 正官得用 | 貴人の助け・上長の知遇を得やすく、事業は順調 | 官に財の生と印の護りがあり、格局清純 |
| 正官被傷 | 食傷が官を損じ、あるいは合い去られ、事業に不利 | 傷官見官、禍百端 |
| 正官過旺 | 虚栄を愛し張り合いを好み、圧力が極めて大きい | 官多ければ殺と為り、善意の管が悪意の圧に変わる |

要点提醒：正官は八字類象の要（かなめ）である。その人が社会で足場を保てるかどうかは、まず正官を見る——正官はあるか。どの柱にあるか。財の養いがあるか。印の護りがあるか。官が清ければ命も清く、官が乱れれば命も乱れる。

『三命通会』正官の核心法則：

- 逢官看印——正官格は印郷を行くを最も喜び、印綬の官を護るを第一の要義とする。官に印なければ孤、印に官なければ虚。
- 官星重見、只作煞推——正官が多く見えれば殺に変じ、もはや吉神としては論じず、これを制して福と為すを要する。
- 時為帰息之地——時辰は旺じすぎた官を節制し、衰えかけた官を補助しうる。吉凶はすべて時の消長にある。
- 五行官星各論：金為官→職位清峻、刑獄決断；木為官→品秩清高、守慎温和；水為官→謙和得衆、循序昇進；火為官→性烈にして刑を用い、起伏は一定しない；土為官→重厚で犯し難く、法令分明。

『三命通会』の正官歌訣は次の三首である。月支に正気の官星を用い、年時には財印の巡り来るを喜ぶ。破・害・沖・空のいずれも犯さなければ、富貴双全となる。官星はおおむね身の強きを要し、身弱ければ気の旺ずる方を求むべし。印綬と財旺の地を兼ね行き、沖・傷・破がなければ栄える。正官はおおむね純和を要し、四柱に傷なくば科挙に及第する。時上には財の健旺なるに逢うを喜び、柱中には印の多く生ずるを見るを欣ぶ、と。

> 

『相心賦』に云う——「官星愷悌，貴氣軒昂，抱優渥而仁慈寬大，懷豁達而聲韻和揚，丰姿美而秀麗，性格敏而聰明」。官星は和やかで気品高く、厚き恵みを抱いて仁慈寛大、豁達を懐いて声韻は和やかに揚がり、姿は美しく秀麗、性格は敏にして聡明である、と人柄を述べたものである。

## 二、七殺（偏官）類象

攻身の煞、虎を抱いて眠るがごとし——食の制と印の化あれば権、制なく化なければ災。七殺は古に煞と称し、凶神の首であり、専ら身を攻むるを要とする。制あればこれを偏官と謂い、制なければこれを七殺と謂う。制伏されれば吉利の面が現れ、助けられれば凶性が現れる。

『子平真詮』偏官を論ず——沈孝瞻曰く、煞は身を攻む、美物に非ざるに似るも、大貴の格には七煞を存するもの多し。蓋し控制宜しきを得れば煞は我が用と為る。大英雄・大豪傑のごとく、馭し難きに似るも、処するに方ありては驚天動地の功も忽焉として就く。これ王侯将相に七煞を存するもの多きゆえんである。また曰く、煞を食を以て制する者は上なり、煞旺じ食強くして身健やかなれば、極めて貴き格と為す、と。

> 

### 2.1 基本定義

| 項目 | 内容 |
| --- | --- |
| 生剋関係 | 同性の我を剋する者（陰陽相同なり、剋制は猛烈にして刀兵のごとし） |
| 五行関係 | 例えば、甲木の日干が庚金を見る（陽金が陽木を剋す） |
| 核心職能 | 身を攻むるを要とする。煞は敢えて想い敢えて行い、一途に前進し、決を下せば結果を顧みない。粗暴・衝動の象徴であり、衝動ゆえに違法犯罪を招きやすい |

### 2.2 多次元類象

| 次元 | 正面 | 負面／注意事項 |
| --- | --- | --- |
| 性格特徴 | 激烈、果断、開拓心に富み、進取の気性あり、執行力が強く、威厳がある | 好闘、虚栄を愛す。財殺が同時に現れるとき：酒色と闘争を好み、他人と衝突しやすく、事を過度に急進し、自負心があり、報復心を帯び、邪道に入りやすい。七殺が旺じすぎれば虚栄を愛し張り合いを好み、虚栄心に苦しめられやすい |
| 七殺旺而無制 | — | 身また弱者：自分の意見がなく、臆病で事を恐れ、刺激を受けやすく、性格は抑鬱的 |
| 人物類象 | 上司、武装部隊、警備員、警察などの法執行の人員 | 小人、凶悪な者。七殺が旺じて制なければ小人の是非を受けやすい |
| 六親類象 | 男命は子女、女命は情夫 | 女命で財殺が同時に現れ、七殺に食神の制伏なきとき、悪質な男に遇いやすく、あるいは家庭内暴力を受けやすい |
| 事務類象 | 権力、武力 | 凶災、牢獄、紛糾、悪勢力、小人、敵、災難、暴力、圧力、疾病、訴訟・牢獄、刑事訴訟 |
| 性情類象 | 敢えて想い、敢えて行う、一往無前 | 忌と為れば理想は高く実行が伴わず、勇あれど謀なし。衝動により違法犯罪を招きやすい |
| 職業類象 | 危険度の高い職業、高リスク職業、軍警法に従事、行政管理（法執行の性質を帯びる） | 違法犯罪あるいはグレーゾーンの行為。七殺に制なければ暴力団や投機の人となりやすい |
| 健康類象 | 圧力系統（急性の圧力）、外傷、疾病、精神的緊張 | 殺が旺じて身を攻め制なき者は、傷痍・突発的な疾病を主る |
| 場所類象 | 監獄、警察機関、武装部隊の駐屯地 | — |
| 功能作用 | 護財、生印、攻身、制劫 | 七殺に制なければ身を攻め、災禍を主る |

### 2.3 七殺の有制と無制

| 状態 | 名称 | 表現 |
| --- | --- | --- |
| 有制（食神・傷官の剋制） | 偏官 | 凶性が制せられ、正面の力量に転化する——生殺の権を掌り、威猛の才を成す |
| 無制 | 七殺 | 凶性大いに発し、災禍・圧力・疾病を主る |
| 旺而無制・身また弱 | 七殺攻身 | 自分の意見がなく、臆病で事を恐れ、刺激を受けやすく、性格は抑鬱的 |

要点提醒：七殺は猛虎のごとし——八字を見るときの第一反応は「七殺があれば凶」ではなく、「この七殺は制せられているか」である。食神が来て制し、印綬が来て化し、傷官が煞に合する、いずれも制煞の有効な手段である。古の豪傑には七殺を持つ者が多い——要は制化にある。

『三命通会』七殺の制化三法：

- 食神制殺（強硬手段）——「一煞倡亂，獨力可擒」。単一の七殺が禍を為すとき、一位の食神で制伏しうる。これが制殺の第一法である。
- 印綬化殺（柔軟手段）——「衆煞混行，一仁可化」。多殺混雑のとき、一つの印星（仁＝印）で解消しうる。徳を以て暴を化し、敵を化して友と為す。
- 傷官合殺——傷官が殺に合する。智を以て勝ち、柔中に剛を帯びる。

## 三、正偏財類象

養命の源、身強くして任じうる——正財は安定し、偏財は流動する、蔵すれば破れず露わなれば分かつ。財は養命の源、人々の欲するところなれど、人々の得るところに非ず。財星は偏正を分かたず、皆な美物にして、統べて財星と称し、一般に吉神として論ずる。

『子平真詮』財を論ず——沈孝瞻曰く、財は我が剋する使用の物なり、能く官を生ずるを以て美と為す。財帛と為し、妻妾と為し、才能と為し、駅馬と為す、皆な財の類なり。また曰く、財は根深きを喜び、太だ露わなるは宜しからず。身強くして傷官を透さず、七煞に混じざれば、貴格なり、と。

> 

### 3.1 正財と偏財の基本定義

| 項目 | 正財 | 偏財 |
| --- | --- | --- |
| 生剋関係 | 異性の我が剋する者（陰陽相異なり、名正言順） | 同性の我が剋する者（陰陽相同なり、意外偶然） |
| 五行関係 | 例えば甲木が己土を見る | 例えば甲木が戊土を見る |
| 収入性質 | 合法的で安定した収入：給与、固定収入、低リスク投資 | 意外で非固定の収入：横財、投機の財、高リスク投資、出所不明の財 |
| 男命六親 | 妻 | 愛人、側室 |
| 核心特徴 | 安定持続 | 財来たり財去り、聚散常なし |

### 3.2 多次元類象

財星総綱：財は養命の源である。財の旺ずる人は芸術の才が高く、気質を備える。財と印は一組の矛盾である——印は保守・守旧を表し、財は独創・融通を表す。

『三命通会』財星の核心法則：

- 一馬在廐，人不敢逐；一馬在野，人共逐之——財星が位を得（庫蔵あり、深く蔵して露わさず）、人敢えて奪うなし。財星が外露し（虚浮して天干にあり）、衆人争奪す。財は蔵を宜しとし露を宜しとせず、蔵すれば豊厚、露わなれば破れやすい。
- 財旺身衰，逢生即死——財が太だ旺じて身が太だ弱ければ、さらに財運を行きあるいは財星の生扶に逢えば、反って性命の憂いがある。これが「富屋貧人」の極端である——財は福に非ずして禍となる。
- 正官佩印，不如乗馬——正官に印を配するは善きも、官星が財（馬＝財）の生扶を得るに如かず、直接にして力がある。印の官を護るは「守」、財の官を生ずるは「攻」——攻守を兼ね備えにして初めて上と為す。

## 四、印綬類象

生身の母、蔭庇受福——正印は文貴の基、偏印は食を見れば反目して梟と成る。印綬は権柄と為り、また父母生身の義と為り、一切我に有利なるものの象徴と為る。正印偏印を分かたず、統べて印綬と称す。正印は一般に吉神、偏印は食神に遇えば凶神と為り、梟神と称す。

『子平真詮』印綬を論ず——沈孝瞻曰く、「印綬喜其生身，正偏同為美格，故財與印不分偏正，同為一格而論之」。印綬の格局は一様でない。印ありて官を透す者は、官星清純なるを貴とす。印ありて食傷を用いて秀を泄す者は、身強く印旺じて其の太過を恐れ、身を泄して以て秀気と為す。印多く財を用いる者は、印重く身強く、財を透して以て太過を抑う。

### 4.2 多次元類象

印綬総綱：印綬は身を生ずることができ、我が気の源となり、父母の生むところの義のごとくである。官殺を泄し、傷を御し、食を挫く——これが印綬の功能である。

## 五、食神類象

寿星福星、制殺第一——才能を以て財を生じ温和従容、梟に奪わるれば福寿倶に損ず。食神は七殺の天敵、専ら制殺を要とする。ゆえに寿星と称す——寿夭は往々にして食神の状態を見る。一般に吉神として論ずる。

『子平真詮』食神を論ず——沈孝瞻曰く、食神はもともと泄気に属するが、よく正財を生ずるがゆえにこれを喜ぶ。ゆえに食神生財を美格とする、と。

> 

食神の格局は一様でない。財を生ずる者は身強く食旺じて財が透ければ大貴、煞に就き印する者は最も権威顕赫、金水の食神に煞を用うる者は貴にしてかつ秀である。また「藏食露傷，主人性剛」と曰う——食を蔵し傷を露わす者は、その人性剛し。食傷の蔵と露の別によって、人の剛柔を断じうる。

### 5.1 基本定義

| 項目 | 内容 |
| --- | --- |
| 生剋関係 | 同性の我が生ずる者（陰陽相同なり、温和で伝統的な才芸の展現） |
| 五行関係 | 例えば、甲木の日干が丙火を見る（陽木が陽火を生ず） |
| 核心職能 | 七殺の天敵、専ら制殺を要とする。食神制殺はこれを「善を以て悪を制す」と謂う——日干をして安然として無事たらしむ |

### 5.2 多次元類象

食神総綱：食神は寿星であり、福星である。食神の状態がよければ身体は健康長寿、食神が刑衝剋奪に逢えば意外の傷災が現れやすく、重ければ夭折の象あるいは官非牢獄の災いを帯びる。食神の人は天性温和で、同情心と想象力に富み、表現を善くする——しかし旺じて制なければ考え多くしてなすこと少なく、大言壮語に流れやすい。

## 六、傷官類象

技芸の星、損官の患——聡明叛逆、印を佩れば貴、傷尽きて官を見れば禍百端。傷官は正官の天敵、専ら損官を要とする。「傷官見官、禍百端」、一般に凶神として論ずる。しかし傷官はまた技芸の星でもある——制化宜しきを得れば、才能が溢れる。

『子平真詮』傷官を論ず——沈孝瞻曰く、傷官は吉神に非ざるも、実に秀気なり、ゆえに文人学士は傷官格の内に之を得るもの多し。しかも夏木の水を見、冬金の火を見るは、また秀の尤も秀なる者なり、と。

> 

傷官格の変化は尤も多い——財を生ずる者は凶を転じて吉と為し、印を佩る者は傷を制して貴と為し、官を用うる者は金水独り宜し。その要旨は次のとおりである——「查其氣候，量其強弱，審其喜忌，觀其純雜，微之又微，不可執也」。気候を査し、強弱を量り、喜忌を審らかにし、純雑を観る。微の又微にして、執るべからず、と。

| 五行関係 | 例えば、甲木の日干が丁火を見る（陽木が陰火を生ず） |
| 核心職能 | 正官の天敵、専ら損官を要とする。傷官が正官を見れば、勢いを恃みて之を欺き、日干を理法の外に放任する |

傷官総綱：傷官は人の思考・天賦・霊感・芸術の才能を表し、技芸の星である。主に文芸技術の面に現れ、芸術創作や講演・表現の能力などがそれである——ゆえに演芸界・文芸界の芸人には傷官を持つ者が多い。傷官はまた独創と流行を表し、潮流に即き、飲食と遊興・流行とファッションと関わる。同時に傷官は、正規に循わず、常識にとらわれずに打ち、近道を好む傾向をも表す。

## 七、比肩類象

兄弟相助け、また財福を分かつ——身弱くして助けを得れば貴、身旺にして争いを成せば累。比肩は兄弟の義と為り、協力・分かち合い・競争・争奪の意を表し、必ずしも破財を表さない。日旺は一般に凶神として論ずるが、一概には論じられない。

『子平真詮』建禄月劫を論ず——沈孝瞻曰く、建禄とは月建が禄堂に逢うこと、禄は即ち劫である。ゆえに建禄と月劫は同一格と為すべく、必ずしも分加するを要せず、皆な干支を透すを以てし、別に財官煞食を取りて用と為す、と。

> 

禄劫格は別に財官を取りて用と為す。禄劫が官を用うれば、財印の相随うを喜び、孤官に輔なきは不可。禄劫が財を用うれば、須らく食傷を帯びて劫を化し財を生ずべし。禄劫が煞を用うれば、必ず制伏せざるべからず。また曰く、禄劫の格、財官なくして傷食を用うるは、其の太過を泄し、また秀気と為す。唯だ春木秋金、之を用うれば則ち貴、蓋し木は火に逢えば則ち明らか、金は水を生じて則ち霊なり、と。

## 八、劫財類象

奪財の首、凶なること比肩に過ぐ——制あればチーム事を成し、制なきは刀兵財を破る。劫財は財星の天敵、専ら奪財を要とし、すなわち掠奪して財を奪うの義である。ゆえにまた「逐馬」と称す。日旺は一般に凶神として論ずるが、一概には論じられない。

『子平真詮』陽刃を論ず（陽刃すなわち劫財の甚だしき者）——沈孝瞻曰く、陽刃は我が正財を劫する神、すなわち正財の七煞である。禄の前の一位、惟だ五陽にのみ之あり、ゆえに陽刃と為す。劫と曰わずして刃と曰うは、劫の甚だしきなり。刃は伏制を宜しくし、官煞いずれも宜しく、財印相随えば、尤も貴顕と為す、と。

> 

陽刃が官を用うれば、刃を透しても憂えず——官は能く刃を制す。陽刃が煞を露わし、刃を透せば成ることなし——刃は能く煞に合するも則ち功なし。陽刃が財を用うるは、格の喜ばざるところなれど、財の根深くして傷食を用いて刃を転じて財を生ずれば、また富に就くべし。

| 核心職能 | 財星の天敵、専ら奪財を要とする。劫財は財を奪い福を奪い命を奪い、奪いうる一切の物を奪う |

### 8.2 多次元類象

劫財総綱：劫財とはすなわち掠奪して財を奪うの義であり、ゆえにまた「逐馬」と称す。経に云う、「無財遇劫，縱非財年，亦須見破」——これにより劫財の財を奪う苛烈さがわかる。劫財は通常、兵刃・刀槍・手術・災禍を表す。劫財がさらに傷官に遇えば「背祿逐馬」と称し、『珞琭子』に云う、「背祿逐馬，守窮途而悽惶」。馬とは貴気・官星・禄財星である——劫財と傷官が並び見えれば、財官倶に損ずる。

要点提醒：劫財と比肩は同じく「身を助け財を奪う」類に属するが、劫財の奪財はさらに苛烈である——比肩は「財を分かつ」、劫財は「財を奪う」。分財にはなお話し合いの余地があるが、奪財には余地がまったくない。経に「無財遇劫，縱非財年，亦須見破」と云うのは、その凶なることを示すに足る。劫財を見る三つの問い。一、身辺に財星があるか。財があれば奪い、財がなければ当面は大した障りはない。二、官殺が劫を制して財を護るか。官殺は劫を制して財を護り、凶を転じて吉と為しうる。三、劫財は傷官に遇っているか。劫財が傷官に遇うのは「背祿逐馬」である——財星は劫され、官星は傷られ、金銭と地位をともに失う、大凶の組合せである。さらに、劫財は兵刃・手術をも表す——流年に劫財が沖剋される者は、意外の傷災を防ぐがよい。

『三命通会』比劫の核心法則：

- 權刃復行權刃，刀藥亡身——権力（官殺）と羊刃（劫財）が重なり、さらに権刃の大運に逢えば、刀兵毒薬の災いがある。これが劫財の最も凶なる応——劫刃重ねて見え、身旺にして制なければ、必ず血光を見る。
- 兄弟破財財得用——比肩は財を奪うとはいえ、財は反って己の用とする所と為りうる（チーム生財の象）。比劫は必ず財を奪うものではなく、身旺・身弱を見るべきである。身弱が比劫の助けを得るのは、反って貴人である。
- 夫妻隨娶隨傷，蓋為比肩伏馬——比肩が妻財の下に暗伏し、婚姻は反復多変となる。男命で比劫の重い者は、婚変を防ぐべし。

## 五大経典矛盾

八神の類象を通読したうえで、この五組の矛盾を全局の視野に置いて改めて見直す——どの「怕」の背後にも解消の道があり、どの凶格のなかにも権柄の門が蔵されている。以下、本課の内容を総合し、一つずつ詳解する。

梟印奪食（偏印が食神を制す）——最も危険である。

偏印が食神を見て反目し梟と為れば、福神が剋されて三層の能力が尽く失われる。思想能力（霊感と表現を喪失する）、金を稼ぐ能力（食が財を生じなければ財源が断裂する）、災病に抗する免疫力（食が殺を制さなければ殺が来て身を攻める）の三つである。食神が刑衝剋奪に逢えば、軽ければ才能が抑えられ思想が枯渇し、重ければ意外の傷災・訴訟、さらには牢獄の災いとなる。女命で旺印が食傷を剋すれば、不妊・流産・子女の縁薄きを主る。食神が太だ旺じて財なき者は、奪われずとも、また利己的で気が小さい者が多い——これは本課食神章の補足要点である。解消の法：財を用いて印を壊し食を護る——梟と食が対峙するとき、財星を引き入れれば梟は転じて財を剋しに去り、食神は救われる。これが財破印護食の通路である。

比劫奪財（比劫が財星を剋す）——最もよく見られる。

財は養命の源、男命の妻星である。比劫が分奪すれば、伙伴が財を分かち、破財・共同の損を生じやすい；男命は婚姻困難あるいは婚変となる。劫財は兵刃・刀槍・手術・災禍を表す——「劫財は財を奪い福を奪い命を奪い、奪いうる一切の物を奪う」。劫財がさらに傷官に遇えば「背祿逐馬」と称し、『珞琭子』に「背祿逐馬，守窮途而悽惶」と云う。比肩もまた財を奪うが、協力・分かち合い・競争をも表し、必ずしも即座に破財とはならない——これが本課比肩章の核心の提示である。身弱が比劫の助けを得るのは、反って貴人である。解消の道筋：食傷が比劫を化して財を生ずる、あるいは官星が比劫を制して財を護る。比劫奪財の最終的な判断は日主の強弱にある——身強で財を奪うのは災、身弱で助けを得るのは福である。

食神制殺（食神が七殺を制す）——凶を化して吉と為す。

七殺は凶神の首であり、身を攻むれば傷痍・疾病・牢獄を主り、虎を抱いて眠るがごとくである。食神は七殺の天敵、専ら制殺を要とし、日干をして安然として患なからしむ。ゆえに食神はまた「寿星」と称す。寿夭は往々にして食神の状態を見る——これが本課食神章の第一の要義である。命局に食神制殺ある者は、危険に遇ってもよく険を化して夷と為し、反って権柄と福と為す。食神が煞を用うる者は、軍警法・法執行の属性、あるいは行政管理・起業や経営に宜し。女命は食神を福星とし、食神制殺に力あれば、自身の平安のみならず、よく夫を旺し子を益す。

傷官見官（傷官が正官を剋す）——禍百端。

正官は十神の首、栄身の本であり、傷官は勢いを恃みて人を欺き、日干を理法の外に放任する。二者の力量が互角すれば禍事が絶えず、訴訟・是非・小人を主り、事業は変転が多く、人間関係は緊張する。しかし傷官にはまた別の面がある——思考・天賦・霊感・芸術の才能を表し、正規に循わず、常識にとらわれずに打ち、近道を好む。古に云う、「五制傷官，為禍百端；利物傷官，聰明異端」——これが本課傷官章の核心の弁証である。解消の道筋：傷官は務めずば傷を尽くすべし——傷の尽きざれば、官が来て旺に乗じ、其の禍は言い尽くせない。印を佩れば印を以て傷を制し（学問と修養によって才能を約束する）、財を生ずれば財を以て傷を化す（叛逆を商業的価値へ転化する）。これが二つの解消の大道である。

財壊印（財星が印綬を剋す）——利のゆえに義を失う。

印は名声・学業・母を表し、保守・守旧・手順通りに進むことを表し、学業に利するも柔軟さを欠く。財は独創・融通・現実の利益・芸術の気質・生活の享受を表す。財と印は天生の矛盾の一組である——財が旺じて印を剋する者は経済頭脳があるが学に向かう心がなく、「財多不是讀書人」である；印が旺じて財なき者は博学清高だが生業を善くしない。正財の旺ずる者は母を剋し、母との縁が薄い——これが本課印綬章と財星章の交差する要点である。解消の道筋：官星の通関——財が官を生じ、官が印を生じ、財は印を壊さず反って官印相生の貴格となる。これが五行通関の法が十神の層で示す最良の範例である。

五組の矛盾の総覧：

梟印奪食が最も凶（福神が剋される）、食神制殺が最も吉（凶神が制される）、比劫奪財が最もよく見られる（毎日見られる）。解消の道は生剋の規律のなかに蔵されている——梟印奪食は、財を用いて印を壊し食を護る；比劫奪財は、食傷を以て之を化しあるいは官星を以て之を護る；食神制殺は、食を以て帥と為す；傷官見官は、印を以て枷と為し、財を以て渠と為す；財壊印は、官を以て橋と為す。初学者はまず「梟印奪食、食神制殺、比劫奪財」の三組を覚え、其余は実践のなかで逐次身につけるがよい。進階課程では、十神組合三部作（第10〜12課）が解消の道を逐一詳解する。

## 本章小結

1. 正官 – 異性の我を剋し、温情の約束、正義と責任を主る；女命は夫星、男命は子女
2. 七殺 – 同性の我を剋し、厳しい抑制、果断で覇道的を主る；制あれば偏官、制なければ七殺
3. 正偏財 – 養命の源、偏正を分かたず。正財は安定収入を主り、偏財は意外の財を主る；男命は正財が妻、偏財が愛人；男女を分かたず偏財は父
4. 印綬 – 我を生ずる権柄、偏正を分かたず。正印は正統の学識を主り、偏印は偏門の玄学を主る；食神を見れば梟神奪食
5. 食神 – 同性の我が生じ、温和な才芸、楽観して趣を知るを主る；寿星、七殺の天敵；女命は娘；男女を分かたず祖父母の代
6. 傷官 – 異性の我が生じ、叛逆の才能、聡明で不羈を主る；正官の天敵；女命は息子
7. 比肩 – 同性の同我、協力競争、自信と自分の意見を主る；兄弟友人；身を助けまた財を奪い、旺弱が吉凶を定む
8. 劫財 – 異性の同我、争奪・掠奪、衝動好闘を主る；財星の天敵、財を奪い福を奪い命を奪い、また「逐馬」と称す；傷官に遇えば背祿逐馬
9. 五大経典矛盾 – 梟印奪食（最凶）、比劫奪財（最もよく見られる）、食神制殺（最吉）、傷官見官、財壊印——解消の道は生剋の規律のなかに蔵される

## 練習

### 練習1：正官の識別

問い：女命の八字において、正官は何を表すか。

1. A. 夫
2. B. 父
3. C. 息子
4. D. 母

???+ "答え"
    正解：A
    女命では正官は夫（正夫）、七殺は愛人。
    男命では正財は妻、正官は子女。

### 練習2：七殺の判断

問い：七殺が食神に制伏された後、何と呼ぶか。

1. A. 正官
2. B. 偏官
3. C. 傷官
4. D. 劫財

???+ "答え"
    正解：B
    七殺に制あり（食神・傷官の剋制あり）→ 偏官（凶性が制せられ、正面の力量に転化する）
    七殺に制なし → 七殺（凶性大いに発す）

### 練習3：財星の判断

問い：正財と偏財について、以下の記述のうち正しいものはどれか。

1. A. 正財は不安定な収入を表し、偏財は安定した収入を表す
2. B. 正財は妻、偏財は父（男女を分かたず）
3. C. 正財は愛人を表し、偏財は妻を表す
4. D. 正財は父、偏財は母

???+ "答え"
    正解：B
    正財：安定収入（給与）、男命の妻
    偏財：意外収入（株式売買、博打）、男命の愛人、男女を分かたず父

### 練習4：印星の判断

問い：偏印が食神に遇ったとき、何と呼ぶか。

1. A. 傷官見官
2. B. 梟印奪食
3. C. 比劫奪財
4. D. 財壊印

???+ "答え"
    正解：B
    「梟印奪食」：偏印が食神を剋す → 才能を抑制し、健康に不利、女命は子女に不利。
    傷官見官：傷官が正官を剋す → 禍百端
    比劫奪財：比劫が財星を剋す → 破財の象
    財壊印：財星が印綬を剋す → 貪財にして名声を壊す

### 練習5：十神の功能

問い：食神の主要な功能は何か。

1. A. 生官殺、泄食傷
2. B. 制殺、損官、泄身、生財
3. C. 衛財、生印、抑身、制劫
4. D. 敵官殺、助身、奪財

???+ "答え"
    正解：B
    食神の功能：制殺、損官、泄身、生財
    制殺 → 食神が七殺を制す（災を去る）
    損官 → 食神が正官を損ず（仕事に不利）
    泄身 → 食神が自身の気を泄す
    生財 → 食神が財星を生ず（才能が富に変わる）
