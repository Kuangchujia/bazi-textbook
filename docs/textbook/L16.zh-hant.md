## 一、吉神類神煞

吉神類神煞是八字中起正面輔助作用的星神。學神煞的第一步，就是把下面這幾個最常見的吉神記熟。

### 1.1 天乙貴人

天乙貴人是最重要的一顆吉神，主逢凶化吉、遇難呈祥。查法以日干為準，地支見即為有貴人。口訣雖然看起來像歌謠，但記熟了對排盤判斷很有幫助。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 甲戊並牛羊，乙己鼠猴鄉，丙丁豬雞位，壬癸兔蛇藏，庚辛逢虎馬，此是貴人方 |
| **查法** | 以日干起貴人，地支見者為是 |
| **作用** | 逢凶化吉之星——四柱有貴人，遇事有人幫，遇危難之事有人解救 |

### 1.2 天德貴人

天德貴人以月令為準來查，不同月份出生的人有不同的天德。天德主一生平穩、少病少災，是與月德齊名的吉祥神煞。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 正月生者見丁，二月生者見申，三月生者見壬，四月生者見辛，五月生者見亥，六月生者見甲，七月生者見癸，八月生者見寅，九月生者見丙，十月生者見乙，十一月生者見巳，十二月生者見庚 |
| **查法** | 凡四柱年月日時上見者為有天德貴人 |
| **作用** | 人有天德貴人，一生平穩，少病少災 |

### 1.3 月德貴人

月德與天德並稱”天月二德”，古人認為二德是仁慈善良之象。如果凶煞（如七殺、劫煞）與天月二德同柱，凶性會大大減弱——這是神煞組合運用的一個重要思路。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 寅午戌月生者見丙，申子辰月生者見壬，亥卯未月生者見甲，巳酉丑月生者見庚 |
| **作用** | 天月二德，其人愷悌慈祥，待人至誠仁厚。煞帶天月德，明敏果決而仁厚；食傷帶天月德，聰明秀慧而仁厚。二德以天德為重，月德次之 |

### 1.4 太極貴人

太極貴人主聰明好學、喜歡鑽研深奧的學問。命帶太極的人，對哲學、歷史、宗教、玄學等科目往往有天然的親近感。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 甲乙生人子午中，丙丁雞兔定亨通，戊己兩干臨四季，庚辛寅亥祿豐隆，壬癸巳申偏喜美，值此應當福氣鍾 |
| **作用** | 主聰明好學，有鑽勁，喜文史哲宗教等科目。為人正直，做事有始有終 |

### 1.5 文昌

文昌主文採和學業，命帶文昌的人通常氣質文雅、好學上進。考試運、學習運好的人，往往八字中帶文昌星。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 甲乙巳午報君知，丙戊申宮丁己雞。庚豬辛鼠壬逢虎，癸人見卯入云梯 |
| **查法** | 以年干或日干為主，四柱中地支所見者為是 |
| **作用** | 文昌入命，主聰明過人，逢凶化吉。氣質雅秀，舉止溫文，好學新知，具上進心 |

### 1.6 天醫

天醫主健康和醫術。命帶天醫且生旺的人，不僅自身身體好，還特別適合從事醫療、心理、養生等與健康相關的職業。

| 項目 | 內容 |
| --- | --- |
| **查法** | 正月生見丑，二月生見寅，三月生見卯，四月生見辰，五月生見巳，六月生見午，七月生見未，八月生見申，九月生見酉，十月生見戌，十一月生見亥，十二月生見子。以月支查其它地支 |
| **作用** | 生旺又有貴人相生助——身體健壯，特別適合醫務工作及心理學、哲學等 |

## 二、中性神煞

中性神煞本身沒有固定的吉凶，需結合具體命局判斷。

### 2.1 驛馬

驛馬主走動、奔波、遷移。命帶驛馬的人天性好動，坐不住。商人、軍人、外交官、銷售等經常出差或調動工作的人，八字中往往帶驛馬星。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 申子辰馬在寅，寅午戌馬在申，巳酉丑馬在亥，亥卯未馬在巳 |
| **查法** | 以日支為主，四柱中臨之則為馬星 |
| **作用** | 馬為走動、奔馳之象。主人好動，必有走遍東西南北之行。商人、軍人、外交人員經常出差走動者多帶馬星 |

### 2.2 華蓋

華蓋是一顆孤獨但有深度的星。命帶華蓋的人不愛熱鬧，喜歡獨處思考，對哲學、宗教、玄學、藝術有天然的興趣。很多學者、修行者、藝術家的八字中都帶華蓋。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 寅午戌見戌，亥卯未見未，申子辰見辰，巳酉丑見丑 |
| **查法** | 以年支或日支為主 |
| **作用** | 性情恬淡，雅潔高致，資質聰敏，富於文才與藝術性，傾向於哲學、宗教 |

### 2.3 將星

將星是權力之星，主組織領導能力。命帶將星的人有懾眾之威，適合擔任管理職位。但要注意將星不能處於死絕或被沖破的狀態，否則有名無實。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 寅午戌見午，巳酉丑見酉，申子辰見子，亥卯未見卯 |
| **查法** | 以年支或日支為主，四柱中地支所見者為是 |
| **作用** | 權力之星，具有組織領導指揮才能，有懾眾之威。但死絕衝破者不利 |

### 2.4 桃花（鹹池）

桃花主人緣和情緣，是大家最熟悉也最容易被誤判的神煞。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 申子辰在酉，寅午戌在卯，巳酉丑在午，亥卯未在子 |
| **查法** | 以年支或日支查四柱其它地支 |
| **注意** | 桃花帶羊刃，主多學多能，未免多疾。如見歲運逢衝桃花，會因色犯刑 |

### 2.5 祿神

祿神即十干臨官之位，代表爵祿和福氣。祿在年支為歲祿，月支為建祿，日支為專祿，時支為歸祿——其中歸祿（時柱）最為吉利，有”青云得路”之象。但祿忌落空亡或逢衝，稱為”破祿”，反而主衣食不足。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 甲祿在寅，乙祿在卯，丙戊祿在巳，丁己祿在午，庚祿在申，辛祿在酉，壬祿在亥，癸祿在子 |
| **分類** | 年支→歲祿，月支→建祿，日支→專祿，時支→歸祿 |
| **注意** | 祿落空亡或犯衝謂之破祿，貴人停職剝官，常人衣祿不足 |

### 2.6 魁罡

魁罡是特定的四個日柱——壬辰、庚戌、庚辰、戊戌。命帶魁罡的人性格剛烈、正直果斷、嫉惡如仇。但魁罡需要日主健旺才能發揮作用，日主弱的魁罡反而容易遭遇挫折。

| 項目 | 內容 |
| --- | --- |
| **四柱** | 壬辰、庚戌、庚辰、戊戌 |
| **條件** | 日柱見者為是，需日主健旺 |
| **性格** | 剛烈、正直、勇猛、個性耿直、胸無城府、嫉惡如仇、聰明果斷、善用權力 |

### 2.7 羊刃（陽刃）

羊刃即陽干帝旺之位（甲卯、丙戊午、庚酉、壬子），是祿過則刃生的極限狀態。羊刃剛烈暴戾，身強遇之是火上澆油，身弱有羊刃反而是幫身的好東西。如果天月二德同柱，可以化解羊刃的凶性。

| 項目 | 內容 |
| --- | --- |
| **查法** | 甲卯乙寅丙戊午，丁己巳庚酉辛申，壬子癸亥 |
| **特性** | 剛烈、暴戾、激發、急躁。祿過則刃生，功成當退不退 |
| **身強** | 不喜羊刃，有天月二德相助可以消災 |
| **身弱** | 有羊刃可以助身 |

## 三、凶神類神煞

凶神類神煞代表阻礙、損失和不利因素。神煞僅供參考，不宜過度解讀。

### 3.1 空亡

空亡是最特殊的一類凶神——它不是”壞”，而是”空”。求財見空亡，求之不得；求官見空亡，虛有其名。空亡落在不同的柱位，影響不同的親緣領域。

| 項目 | 內容 |
| --- | --- |
| **查法** | 以日柱為主，柱中年月時支見者為空亡 |
| **含義** | 求之不得即為空亡 |

空亡落在不同柱位，對應不同人生面的”空了”。下面這張表幫你快速判斷：

| 位置 | 信息 |
| --- | --- |
| **年支空亡** | 祖緣淡薄，祖輩有早故之人或祖業空；母空（辭世/改嫁/出走/母不顧子） |
| **月支空亡** | 家庭觀念淡薄，無兄弟姐妹或兄弟姐妹無靠 |
| **時支空亡** | 不利子息，主無子女、子女多流產、夭折、身體欠佳 |

### 3.2 劫煞

劫煞代表外部力量對你財物的劫奪——”自外奪之謂之劫”。劫煞落在哪個柱位，那個柱位對應的人或事就容易被外人侵佔、搶奪。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 申子辰見巳，亥卯未見申，寅午戌見亥，巳酉丑見寅 |
| **含義** | 劫者，奪也，自外奪之謂之劫。在十二長生訣中處絕地 |

### 3.3 亡神

亡神與劫煞相反——”自內失之謂之亡”。劫煞是外人來搶，亡神是自己內部出問題，比如決策失誤、自己把機會搞砸。但如果亡神與吉神同柱，反而可能壞事變好事。

| 項目 | 內容 |
| --- | --- |
| **口訣** | 寅午戌見巳，亥卯未見寅，巳酉丑見申，申子辰見亥 |
| **含義** | 亡者，失也，自內失之謂之亡。劫在五行絕處，亡在五行旺處 |
| **注意** | “亡神入命禍非輕，算盡機關心不寧。”但與吉神同柱，反為好事 |

### 3.4 天羅地網

辰為天羅，戌為地網，男忌天羅，女忌地網。大運流年遇到天羅地網，容易有官司牢獄或嚴重的疾病災禍，需要特別留意。

| 項目 | 內容 |
| --- | --- |
| **定義** | 辰為天羅，戌為地網。男忌天羅，女忌地網 |
| **作用** | 主疾病之災，牢獄之災，大運流年遇之，於人不利 |

### 3.5 陰陽差錯

陰陽差錯是十二個特定的日柱，主家庭關係不協調。女命帶之容易與夫家相處不融洽，男命帶之容易與妻家有是非。

| 項目 | 內容 |
| --- | --- |
| **查法** | 丙子、丁丑、戊寅、辛卯、壬辰、癸巳、丙午、丁未、戊申、辛酉、壬戌、癸亥十二日 |
| **女命** | 公姑寡合，妯娌不足，夫家冷退 |
| **男命** | 主退外家，與妻家是非寡合 |

### 3.6 孤鸞煞

孤鸞煞主孤獨和婚姻不順。查法是日柱和時柱同時出現孤鸞煞日中的任意兩組，這比單神煞的判斷要更謹慎一些——兩個位置同時出現才構成孤鸞格。

| 項目 | 內容 |
| --- | --- |
| **查法** | 乙巳、丁巳、辛亥、戊申、壬寅、戊午、壬子、丙午。四柱日時同時出現以上任何兩組者為是 |
| **含義** | 主孤獨、不順、克夫克妻 |

## 四、神煞運用的重要原則

### 4.1 《命理約言》的精闢論述

> **“凡人命吉凶，皆由格局運氣，安可偶合神煞而信之？”** ——陳素庵《命理約言》
> **釋義**：人的命運吉凶，都是由格局和運氣決定的，怎麼可以偶然巧合神煞就相信呢？

### 4.2 對神煞的正確態度

- **主次分明**：五行生克、十神關係與格局判定是命理學的主體
- **神煞為輔**：神煞是神助的因素，僅作輔助參考，不可喧賓奪主，不宜過度解讀

### 4.3 學習建議

- **五行生克**：核心
- **十神關係**：基石
- **格局判定**：關鍵
- **神煞**：神助因素，僅作輔助參考

## 本章小結

1. **吉神類神煞** – 天乙貴人（逢凶化吉）、天月二德（仁厚）、太極貴人（聰明好學）、文昌（聰慧）、天醫（健康）
2. **中性神煞** – 驛馬（走動）、華蓋（哲學宗教）、將星（權力）、桃花（情感）、祿神（爵祿）、魁罡（剛烈）、羊刃（暴戾）
3. **凶神類神煞** – 空亡（求之不得）、劫煞（外奪）、亡神（內失）、天羅地網（牢獄）、陰陽差錯（婚姻不順）、孤鸞煞（孤獨）
4. **核心原則** – 五行生克、十神關係為主，神煞為輔，不可喧賓奪主
