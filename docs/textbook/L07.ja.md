# 第7課 長生十二宮

[简体中文](/textbook/L07/) ｜ [繁體中文](/zh-hant/textbook/L07/) ｜ [English](/en/textbook/L07/) ｜ **日本語** ｜ [한국어](/ko/textbook/L07/)

## 一、長生十二宮とは

『四言独歩』は進退を論じて云う——「進気退気，命物相争；進気不死，退気不生」。進気なれば死せず、退気なれば生ぜず、進気と退気のあいだに命と物とが相争う、と。

『五言独歩』はその義を申べて云う——「進気死不死，退気生不生；終年無発旺，猶忌少年刑」。進気なれば死すとも死せず、退気なれば生ずとも生ぜず、終年発旺なく、なお少年の刑を忌む、と。

長生十二宮の本質は、まさにこの「進気」と「退気」の消長にある。天干が進気の通路（長生→帝旺）にあれば、弱くとも凶ならず、生機は密かに蔵される。退気の通路（衰→絶）にあれば、旺んでも長くは続かず、力は尽きんとする。天干の状態を判断するには、絶対的な強弱を見るよりも、どの通路にあるかを見るほうが重要である。

### 1.1 五行の旺衰と四季の巡り

五行は四季に生じ、令を得れば旺んとなる。

- 春季・木旺 → 木は火を生じ、火は相；木は水の生に頼り、水は休；火は金を剋し、金は囚；木は土を剋し、土は死。
- 夏季・火旺 → 火は土を生じ、土は相；火は木の生に頼り、木は休；水は火を剋し、水は囚；火は金を剋し、金は死。
- 六月・土旺 → 土は金を生じ、金は相；土は火の生に頼り、火は休；木は土を剋し、木は囚；土は水を剋し、水は死。
- 秋季・金旺 → 金は水を生じ、水は相；金は土の生に頼り、土は休；火は金を剋し、火は囚；金は木を剋し、木は死。
- 冬季・水旺 → 水は木を生じ、木は相；水は金の生に頼り、金は休；土は水を剋し、土は囚；水は火を剋し、火は死。

> 

『淵海子平』は生旺衰絶を論じて云う——「不可専泥於生旺而吉、衰敗而凶，当以活法推之」。生旺を吉とし衰敗を凶として専ら泥むべからず、活法をもって推すべし、と。

長生十二宮は、単純に「旺＝良し、衰＝悪し」というものではない——身旺にして帝旺となり制なければ、かえって災禍となる。身が衰地にあっても生扶あれば、また福を発することもできる。十二宮の本質はラベルを貼ることではなく、エネルギーの通路を見ることにある。

> 

### 1.2 長生十二宮の由来

『考原』に曰く——「木長生於亥，火長生於寅，金長生於巳，水長生於申，土亦長生於申，寄生於寅」。木は亥に長生し、火は寅に長生し、金は巳に長生し、水は申に長生し、土もまた申に長生して寅に寄生する、と。

それぞれ長生・沐浴・冠帯・臨官・帝旺・衰・病・死・墓・絶・胎・養の順に、十二辰を巡る。蓋し天道は循環し、生生として已まざるなり。

十干は長生十二宮に寄生し、循環断えることなく、巡り巡って繰り返す。そのありさまはおおむね人の一生と同じであり、十二宮を巡ることもまた人世の輪廻のごとくである。

> 

『喜忌篇』は絶処逢生を論じて云う——「五行絶処，即是胎元，生日逢之，名曰受気」。五行の絶処はすなわち胎元であり、生日にこれを逢うを名づけて受気と曰う、と。

十二宮の最も精妙なところは循環にある——絶処はすなわち胎位であり、死処は新生を孕む。これは悲観ではなく、太極の理である。陰が極まれば陽が生じ、死と生とは二つにあらず。長生の後は必ず帝旺へと向かい、帝旺の後は必ず衰絶に帰し、絶処に一陽来復してまた胎養に入る。十二宮が一巡すれば、それは一つの完全な生命の輪廻である。

> 

## 二、十二宮の各段階

### 2.1 十二宮の逐位解説

長生十二宮は、人が出生してから死に至るまでの十二の段階のごときものである。

長生（旺）——万物が萌え発する、人の降生のごとし。あらゆる新たな始まり、新たな機会、新たな生命力が湧き出る段階。

沐浴（弱・敗地）——嬰児が洗浴して汚れを去る。命理ではまた咸池と名づけ、桃花・感情のもつれを主り、力量はなお安定しない。

冠帯（旺）——万物が漸く栄え、小児が衣を着て帽を戴くことができる。すでに裸形の弱を脱し、社会の役割に入りはじめる。

臨官（旺・またの名を禄）——成人し、教化育成して人を率いることができる。事業成り、能力成熟し、前面に出て独りで任に当たる。

帝旺（旺）——壮盛の極みに至り、帝王を輔佐することができる。頂点はすでに来たが、盛極まれば必ず衰う——帝旺の後は、すなわち衰である。

衰（平淡）——盛極まって衰え、頂点より下行に転ずる。一気に転落するのではなく、勢いが逆転しはじめるのである。

病（平淡）——人が病を患うがごとく、万物が困憊する。力量は明らかに衰退し、休養と調理を要する。

死（弱）——気尽き形死し、力量は谷底に落ちる直前の最低点に至る。

墓（弱・またの名を庫）——死して墓に帰し、力量は封印され収蔵される。終点であると同時に、蓄えでもある。

絶（弱）——前の気はすでに絶え、後の気は未だ至らず。徹底的に空寂であるが、また一陽来復の前夜でもある。

胎（旺・新生）——父母の気を受け、結聚して胎となる。絶処より生じ、無限の生機を秘める。

養（旺・新生）——胎を母腹に養い、まさに生まれんとする。勢いを蓄えて発を待ち、新たな一巡の循環がまさに始まらんとする。

> 

## 三、力量の比較

十二宮は運勢の角度から三つの陣営に分けられ、日主が現在の地支のなかで持つ「下地（底色）」を直接に決定する。

四旺運——長生・冠帯・臨官・帝旺。旺盛な運勢を表し、上昇の通路にあり、エネルギーは充足している。

四悪運——沐浴・死・墓・絶。劣悪な運勢を表し、エネルギーは低迷するか封蔵されている。このうち沐浴はまた敗地／咸池と名づけ、桃花と情感の不安定を主り、悪運に帰するとはいえ、死・墓・絶のように徹底したどん底ではない。

平淡運——衰・病・胎・養。平淡な過渡期を表し、旺んでも悪しくもなく、勢いを蓄えて変を待つ。

以上の三種類は基礎である——しかしより本質的なのは、十二宮の背後にあるエネルギーの通路を見極めることである。長生から帝旺までは進気であり、エネルギーはしだいに上昇する。衰から養までは退気であり、エネルギーは徐々に消退する。命を断ずる際に天干がどの通路にあるかを見ることは、旺弱を単独で見るよりも重要である——進気の道にあれば弱くとも凶ならず、退気の道にあれば旺んでも長からず。詳しくは第2課の四象理論を参照されたい。

## 四、十天干の十二宮における状態

### 4.1 陽干の規律

陽は進を主り、進をもって進とする。陽干の長生は、五行相生の起点（我を生ずる者）にある。

### 4.4 四長生・四帝旺・四墓庫

完全な表から一連の規律が見て取れる——すべての天干の長生・帝旺・墓庫は、わずか八つの地支に集中している。

四長生——寅・申・巳・亥。陽干の長生の所在であり、五行の「門戸」と源である。

四帝旺——子・午・卯・酉。陰干の長生の所在であり、五行の極点である。

四墓庫——辰（水庫）・戌（火庫）・丑（金庫）・未（木庫）。五行の貯蔵と帰着点である。

## 本章小結

1. 長生十二宮の由来 – 天道は循環し、生生として已まず、人世の輪廻の十二段階のごとし
2. 十二段階の詳解 – 長生（出生）→沐浴→冠帯→臨官→帝旺→衰→病→死→墓→絶→胎→養（新生）
3. 力量の比較 – 四旺運（長生／冠帯／臨官／帝旺）、四悪運（沐浴／死／墓／絶）、平淡運（衰／病／胎／養）
4. 陽干の規律 – 陽は進を主り、陽干の長生は「我を生ずる者」の位置にある（甲亥、丙寅、戊寅、庚巳、壬申）
5. 陰干の規律 – 陰は逆を主り、陰干の長生は「我が生ずる者」の位置にある（乙午、丁酉、己酉、辛子、癸卯）
6. 四長生 – 寅申巳亥；四帝旺 – 子午卯酉；四墓庫 – 辰戌丑未

## 練習

### 練習1：長生十二宮の順序

問い：長生十二宮の正しい順序は何か。

1. A. 長生→沐浴→冠帯→臨官→帝旺→衰→病→死→墓→絶→胎→養
2. B. 長生→冠帯→沐浴→臨官→帝旺→衰→病→死→墓→絶→胎→養
3. C. 長生→沐浴→冠帯→臨官→帝旺→衰→病→死→絶→墓→胎→養
4. D. 長生→沐浴→冠帯→帝旺→臨官→衰→病→死→墓→絶→胎→養

???+ "答え"
    正解：A
    正しい順序：長生→沐浴→冠帯→臨官→帝旺→衰→病→死→墓→絶→胎→養
    循環の規律：出生から死へ、さらに新生へと、巡り巡って繰り返す。

### 練習2：陽干の長生の位置

問い：甲木の長生の地はどこか。

1. A. 寅
2. B. 巳
3. C. 申
4. D. 亥

???+ "答え"
    正解：D
    陽干の長生は「我を生ずる者」（五行相生の母位）にある：
    甲木 → 亥に生ず（水生木）
    丙火 → 寅に生ず（木生火）
    戊土 → 寅に生ず（寅に寄生）
    庚金 → 巳に生ず（土生金）
    壬水 → 申に生ず（金生水）
    速記：甲亥丙寅戊寅同，庚巳壬申是长生。

### 練習3：陰干の長生の位置

問い：辛金の長生の地はどこか。

1. A. 午
2. B. 酉
3. C. 子
4. D. 卯

???+ "答え"
    正解：C
    陰干の長生は「我が生ずる者」にある（退をもって進と為し、陽干の死位に対する）：
    辛金 → 子に生ず（金生水、子は水）
    乙木 → 午に生ず（木生火、午は火）
    丁火 → 酉に生ず（火生金、酉は金）
    己土 → 酉に生ず（酉に寄生）
    癸水 → 卯に生ず（水生木、卯は木）
    速記：乙午丁酉己酉同，辛子癸卯是长生。

### 練習4：四旺運と四悪運

問い：以下のうち「四悪運」に属する組はどれか。

1. A. 長生・冠帯・臨官・帝旺
2. B. 沐浴・死・墓・絶
3. C. 衰・病・胎・養
4. D. 長生・沐浴・冠帯・臨官

???+ "答え"
    正解：B
    三大運勢の分類：
    四旺運：長生・冠帯・臨官・帝旺
    四悪運：沐浴・死・墓・絶
    平淡運：衰・病・胎・養

### 練習5：長生十二宮の実戦

問い：ある人の八字の日干は甲木、月支は亥である。甲木は亥の地でどのような状態にあるか。それは何を意味するか。

1. A. 沐浴——桃花、感情のもつれ
2. B. 長生——強大な生命力があり、新たな始まり
3. C. 帝旺——事業の頂点
4. D. 墓庫——力量が封印される

???+ "答え"
    正解：B
    甲木の長生十二宮表における状態：
    甲木は亥に長生する
    意義：甲木日主にして月支が亥ならば「長生を得る」となり、日主がこの月令において強大な生命力を持つことを表す。人は良い出生環境と起点を得たに似て、きわめて活力に富む。
    同じ理により、異なる天干が異なる地支にある状態を推し量ることができる：
    甲木が午にあるなら：「死」の地にあり、力量は最も弱い
    甲木が卯にあるなら：「帝旺」にあり、力量は最も強い
    実戦のヒント：
    八字を見るとき、日主が「長生を得る」のは良いことである——あなたに活力があり、生命力があることを示す
    日主が「死・墓・絶に遇う」なら悪いことである——あなたに活力がなく、「養精蓄鋭」が必要であることを示す
