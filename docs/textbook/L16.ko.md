# 제16과 신살

## 一、길신류 신살

길신류 신살(神煞)은 사주에서 긍정적인 보조 작용을 하는 별신입니다. 신살을 배우는 첫걸음은 아래의 가장 흔한 길신 몇 가지를 확실히 외워 두는 것입니다.

### 1.1 천을귀인(天乙貴人)

천을귀인은 가장 중요한 길신으로, 흉을 길로 돌리고 어려움을 상서로움으로 바꾸는 것을 주관합니다. 찾는 법은 일간(日干)을 기준으로 하여 지지에서 보이면 곧 귀인이 있는 것으로 봅니다. 구결은 노래처럼 보이지만, 확실히 외워 두면 명반을 판단할 때 큰 도움이 됩니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 甲戊并牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，庚辛逢虎马，此是贵人方<br>갑(甲)·무(戊)는 소·양(丑·未)에 나란하고, 을(乙)·기(己)는 쥐·원숭이(子·申)의 고장이며, 병(丙)·정(丁)은 돼지·닭(亥·酉)의 자리, 임(壬)·계(癸)는 토끼·뱀(卯·巳)에 감추어 있고, 경(庚)·신(辛)은 범·말(寅·午)을 만나니, 이곳이 귀인의 방위입니다 |
| **찾는 법** | 일간에서 귀인을 일으켜, 지지에서 보이는 것을 그대로 인정합니다 |
| **작용** | 흉을 길로 돌리는 별——사주에 귀인이 있으면 일이 생겼을 때 돕는 사람이 있고, 위난을 만나면 구해 주는 사람이 있습니다 |

### 1.2 천덕귀인(天德貴人)

천덕귀인은 월령(月令)을 기준으로 찾으며, 태어난 달에 따라 천덕이 각각 다릅니다. 천덕은 한평생의 안정과 질병·재앙이 적음을 주관하며, 월덕과 이름을 나란히 하는 길상 신살입니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 正月生者见丁，二月生者见申，三月生者见壬，四月生者见辛，五月生者见亥，六月生者见甲，七月生者见癸，八月生者见寅，九月生者见丙，十月生者见乙，十一月生者见巳，十二月生者见庚<br>정월생은 정(丁)을 보고, 2월생은 신(申)을 보며, 3월생은 임(壬)을 보고, 4월생은 신(辛)을 보며, 5월생은 해(亥)를 보고, 6월생은 갑(甲)을 보며, 7월생은 계(癸)를 보고, 8월생은 인(寅)을 보며, 9월생은 병(丙)을 보고, 10월생은 을(乙)을 보며, 11월생은 사(巳)를 보고, 12월생은 경(庚)을 봅니다 |
| **찾는 법** | 사주의 연·월·일·시 어느 기둥에서든 보이면 천덕귀인이 있는 것으로 봅니다 |
| **작용** | 사람이 천덕귀인을 지니면 한평생 안정되고 질병과 재앙이 적습니다 |

### 1.3 월덕귀인(月德貴人)

월덕은 천덕과 함께 ‘천월이덕(天月二德)’이라 불리며, 옛사람은 두 덕을 어질고 선량한 상으로 여겼습니다. 흉살(예: 칠살(七殺), 겁살(劫煞))이 천월이덕과 같은 기둥에 있으면 흉한 성질이 크게 줄어듭니다——이는 신살을 조합하여 운용하는 중요한 사고방식입니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 寅午戌月生者见丙，申子辰月生者见壬，亥卯未月生者见甲，巳酉丑月生者见庚<br>인오술(寅午戌)월생은 병(丙)을 보고, 신자진(申子辰)월생은 임(壬)을 보며, 해묘미(亥卯未)월생은 갑(甲)을 보고, 사유축(巳酉丑)월생은 경(庚)을 봅니다 |
| **작용** | 천월이덕을 지닌 사람은 화평하고 자상하며, 남을 지극한 정성과 인후함으로 대합니다. 칠살이 천월이덕을 지니면 명민하고 과단하며 인후하고, 식상이 천월이덕을 지니면 총명하고 수려하며 인후합니다. 두 덕은 천덕을 중히 여기고 월덕이 그다음입니다 |

### 1.4 태극귀인(太極貴人)

태극귀인은 총명하고 배우기를 좋아하며 깊고 오묘한 학문을 파고드는 것을 주관합니다. 태극을 지닌 사람은 철학·역사·종교·현학 등의 분야에 타고난 친근감을 지니는 경우가 많습니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 甲乙生人子午中，丙丁鸡兔定亨通，戊己两干临四季，庚辛寅亥禄丰隆，壬癸巳申偏喜美，值此应当福气钟<br>갑을(甲乙)생은 자오(子午) 가운데 있고, 병정(丙丁)은 닭·토끼(酉·卯)에서 반드시 형통하며, 무기(戊己) 두 간은 사계(四季)에 임하고, 경신(庚辛)은 인해(寅亥)에서 록이 풍성하며, 임계(壬癸)는 사신(巳申)을 유난히 좋아하니, 이에 해당하면 마땅히 복이 모입니다 |
| **작용** | 총명하고 배우기를 좋아하며, 파고드는 힘이 있고, 문학·역사·철학·종교 등의 과목을 좋아합니다. 사람됨이 정직하고, 일을 시작하면 끝을 봅니다 |

### 1.5 문창(文昌)

문창은 문채와 학업을 주관하며, 문창을 지닌 사람은 대개 기품이 우아하고 배움을 좋아하며 향상심이 있습니다. 시험운과 학습운이 좋은 사람은 사주에 문창성을 지닌 경우가 많습니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 甲乙巳午报君知，丙戊申宫丁己鸡。庚猪辛鼠壬逢虎，癸人见卯入云梯<br>갑을(甲乙)은 사오(巳午)라 그대에게 알리고, 병무(丙戊)는 신(申)의 궁이며 정기(丁己)는 유(酉)라. 경(庚)은 돼지(亥), 신(辛)은 쥐(子), 임(壬)은 범(寅)을 만나고, 계(癸)가 묘(卯)를 보면 구름 사다리에 오릅니다 |
| **찾는 법** | 연간 또는 일간을 위주로 하고, 사주 가운데 지지에서 보이는 것을 그대로 인정합니다 |
| **작용** | 문창이 명에 들면 총명이 남보다 뛰어나고 흉을 길로 돌립니다. 기품이 우아하고 수려하며, 거동이 온화하고, 새로운 지식을 좋아하며, 향상심을 지닙니다 |

### 1.6 천의(天醫)

천의는 건강과 의술을 주관합니다. 천의를 지니고 생왕(生旺)한 사람은 자신의 몸이 좋을 뿐 아니라, 의료·심리·양생 등 건강과 관련된 직업에 특히 적합합니다.

| 항목 | 내용 |
| --- | --- |
| **찾는 법** | 정월생은 축(丑)을 보고, 2월생은 인(寅)을 보며, 3월생은 묘(卯)를 보고, 4월생은 진(辰)을 보며, 5월생은 사(巳)를 보고, 6월생은 오(午)를 보며, 7월생은 미(未)를 보고, 8월생은 신(申)을 보며, 9월생은 유(酉)를 보고, 10월생은 술(戌)을 보며, 11월생은 해(亥)를 보고, 12월생은 자(子)를 봅니다. 월지로 다른 지지를 조사합니다 |
| **작용** | 생왕하고 다시 귀인의 상생 도움이 있으면——몸이 건장하며, 의료 업무와 심리학·철학 등에 특히 적합합니다 |

## 二、중성 신살

중성 신살은 그 자체로 고정된 길흉이 없으며, 구체적인 명국과 결합하여 판단해야 합니다.

### 2.1 역마(驛馬)

역마는 이동·분주·이사를 주관합니다. 역마를 지닌 사람은 타고나기가 움직이기를 좋아하여 가만히 앉아 있지 못합니다. 상인·군인·외교관·영업 등 늘 출장을 다니거나 근무지를 옮기는 사람의 사주에는 역마성이 있는 경우가 많습니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 申子辰马在寅，寅午戌马在申，巳酉丑马在亥，亥卯未马在巳<br>신자진(申子辰)은 말이 인(寅)에 있고, 인오술(寅午戌)은 말이 신(申)에 있으며, 사유축(巳酉丑)은 말이 해(亥)에 있고, 해묘미(亥卯未)는 말이 사(巳)에 있습니다 |
| **찾는 법** | 일지를 위주로 하고, 사주 가운데 이것을 만나면 마성(馬星)이 됩니다 |
| **작용** | 말은 걷고 달리는 상입니다. 주인을 움직이기를 좋아하게 하여, 반드시 동서남북을 두루 다니는 행보가 있습니다. 상인·군인·외교 인원처럼 늘 출장을 다니는 사람은 마성을 지닌 경우가 많습니다 |

### 2.2 화개(華蓋)

화개는 고독하지만 깊이가 있는 별입니다. 화개를 지닌 사람은 번화함을 좋아하지 않고 혼자 생각하기를 즐기며, 철학·종교·현학·예술에 타고난 흥미를 지닙니다. 많은 학자·수행자·예술가의 사주에 화개가 있습니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 寅午戌见戌，亥卯未见未，申子辰见辰，巳酉丑见丑<br>인오술(寅午戌)은 술(戌)을 보고, 해묘미(亥卯未)는 미(未)를 보며, 신자진(申子辰)은 진(辰)을 보고, 사유축(巳酉丑)은 축(丑)을 봅니다 |
| **찾는 법** | 연지 또는 일지를 위주로 합니다 |
| **작용** | 성정이 담백하고, 우아하고 고상하며, 자질이 총민하고, 문재와 예술성이 풍부하며, 철학·종교로 기우는 경향이 있습니다 |

### 2.3 장성(將星)

장성은 권력의 별로, 조직·영도 능력을 주관합니다. 장성을 지닌 사람은 뭇사람을 복종시키는 위엄이 있어 관리 직책을 맡기에 적합합니다. 다만 장성이 사절(死絶)하거나 파·충을 당한 상태에 놓여서는 안 되며, 그렇지 않으면 이름만 있고 실속이 없습니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 寅午戌见午，巳酉丑见酉，申子辰见子，亥卯未见卯<br>인오술(寅午戌)은 오(午)를 보고, 사유축(巳酉丑)은 유(酉)를 보며, 신자진(申子辰)은 자(子)를 보고, 해묘미(亥卯未)는 묘(卯)를 봅니다 |
| **찾는 법** | 연지 또는 일지를 위주로 하고, 사주 가운데 지지에서 보이는 것을 그대로 인정합니다 |
| **작용** | 권력의 별로, 조직·영도·지휘의 재능을 갖추고, 뭇사람을 복종시키는 위엄이 있습니다. 다만 사절·파·충을 당하면 불리합니다 |

### 2.4 도화(桃花)·함지(咸池)

도화는 인연과 정연을 주관하며, 누구나 가장 익숙하게 여기면서도 가장 잘못 판단하기 쉬운 신살입니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 申子辰在酉，寅午戌在卯，巳酉丑在午，亥卯未在子<br>신자진(申子辰)은 유(酉)에, 인오술(寅午戌)은 묘(卯)에, 사유축(巳酉丑)은 오(午)에, 해묘미(亥卯未)는 자(子)에 있습니다 |
| **찾는 법** | 연지 또는 일지로 사주의 다른 지지를 조사합니다 |
| **주의** | 도화가 양인(羊刃)을 지니면 다학다능하나 질병이 많음을 면하기 어렵습니다. 세운(歲運)에서 도화가 충을 만나면 색(色)으로 인해 형벌을 범합니다 |

### 2.5 록신(祿神)

록신은 곧 십간의 임관(臨官) 자리로, 작록과 복을 상징합니다. 록이 연지에 있으면 세록(歲祿), 월지에 있으면 건록(建祿), 일지에 있으면 전록(專祿), 시지에 있으면 귀록(歸祿)입니다——그중 귀록(시주)이 가장 길하여 ‘청운득로(靑雲得路)’의 상이 있습니다. 다만 록은 공망에 떨어지거나 충을 만나는 것을 꺼리며, 이를 ‘파록(破祿)’이라 하여 도리어 의식이 부족함을 주관합니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 甲禄在寅，乙禄在卯，丙戊禄在巳，丁己禄在午，庚禄在申，辛禄在酉，壬禄在亥，癸禄在子<br>갑(甲)의 록은 인(寅), 을(乙)의 록은 묘(卯), 병·무(丙戊)의 록은 사(巳), 정·기(丁己)의 록은 오(午), 경(庚)의 록은 신(申), 신(辛)의 록은 유(酉), 임(壬)의 록은 해(亥), 계(癸)의 록은 자(子)에 있습니다 |
| **분류** | 연지→세록(歲祿), 월지→건록(建祿), 일지→전록(專祿), 시지→귀록(歸祿) |
| **주의** | 록이 공망에 떨어지거나 충을 범하면 파록(破祿)이라 하여, 귀인은 정직·삭관을 당하고 보통 사람은 의록이 부족합니다 |

### 2.6 괴강(魁罡)

괴강은 특정한 네 일주——임진(壬辰)·경술(庚戌)·경진(庚辰)·무술(戊戌)입니다. 괴강을 지닌 사람은 성격이 강렬하고 정직하며 과단하고, 악을 원수처럼 미워합니다. 다만 괴강은 일주가 건왕해야 제 역할을 하며, 일주가 약한 괴강은 도리어 좌절을 겪기 쉽습니다.

| 항목 | 내용 |
| --- | --- |
| **사주** | 임진(壬辰)·경술(庚戌)·경진(庚辰)·무술(戊戌) |
| **조건** | 일주에서 보이는 것을 그대로 인정하며, 일주가 건왕해야 합니다 |
| **성격** | 강렬하고, 정직하며, 용맹하고, 성품이 곧으며, 속이 없고, 악을 원수처럼 미워하며, 총명하고 과단하며, 권력을 잘 씁니다 |

### 2.7 양인(羊刃·陽刃)

양인은 곧 양간의 제왕(帝旺) 자리(갑묘(甲卯)·병무오(丙戊午)·경유(庚酉)·임자(壬子))로, 록이 지나면 인이 생긴다는 극한 상태입니다. 양인은 강렬하고 포악하여, 신강한 사람이 만나면 불에 기름을 붓는 격이고, 신약한 사람이 양인을 지니면 도리어 몸을 돕는 좋은 것입니다. 천월이덕이 같은 기둥에 있으면 양인의 흉한 성질을 풀어 줄 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| **찾는 법** | 甲卯乙寅丙戊午，丁己巳庚酉辛申，壬子癸亥<br>갑묘(甲卯)·을인(乙寅)·병무오(丙戊午), 정기사(丁己巳)·경유(庚酉)·신신(辛申), 임자(壬子)·계해(癸亥) |
| **특성** | 강렬하고, 포악하며, 격발하고, 조급합니다. 록이 지나면 인이 생기니, 공을 이루면 마땅히 물러나야 하는데 물러나지 않습니다 |
| **신강** | 양인을 좋아하지 않으며, 천월이덕의 도움이 있으면 재앙을 소멸할 수 있습니다 |
| **신약** | 양인이 있으면 몸을 도울 수 있습니다 |

## 三、흉신류 신살

흉신류 신살은 장애·손실·불리한 요인을 나타냅니다. 신살은 참고용일 뿐이며, 지나치게 해석해서는 안 됩니다.

### 3.1 공망(空亡)

공망은 가장 특수한 흉신입니다——‘나쁘다’가 아니라 ‘비었다’입니다. 재물을 구하는데 공망을 보면 구하여도 얻지 못하고, 관을 구하는데 공망을 보면 이름만 있고 실속이 없습니다. 공망이 놓인 기둥에 따라 영향을 받는 인연의 영역이 달라집니다.

| 항목 | 내용 |
| --- | --- |
| **찾는 법** | 일주를 위주로 하고, 사주 가운데 연·월·시지에서 보이면 공망입니다 |
| **의미** | 구하여도 얻지 못함이 곧 공망입니다 |

공망이 놓인 기둥이 다르면 인생의 다른 국면이 ‘비는’ 것에 대응합니다. 아래 표가 빠른 판단에 도움이 됩니다.

| 위치 | 정보 |
| --- | --- |
| **연지 공망** | 조상 인연이 담박하여, 조상 중 일찍 세상을 떠난 사람이 있거나 조업이 비었습니다. 모친이 빔(별세/재가/가출/모친이 자식을 돌보지 않음) |
| **월지 공망** | 가정 관념이 담박하고, 형제자매가 없거나 형제자매가 의지할 데가 없습니다 |
| **시지 공망** | 자식에게 불리하여, 자식이 없거나 자식이 유산·요절하는 일이 많고 몸이 좋지 않습니다 |

### 3.2 겁살(劫煞)

겁살은 외부의 힘이 당신의 재물을 빼앗는 것을 나타냅니다——‘밖에서 빼앗는 것을 겁이라 한다(自外奪之謂之劫)’. 겁살이 어느 기둥에 놓이면 그 기둥에 해당하는 사람이나 일이 외부인에게 침범·탈취되기 쉽습니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 申子辰见巳，亥卯未见申，寅午戌见亥，巳酉丑见寅<br>신자진(申子辰)은 사(巳)를 보고, 해묘미(亥卯未)는 신(申)을 보며, 인오술(寅午戌)은 해(亥)를 보고, 사유축(巳酉丑)은 인(寅)을 봅니다 |
| **의미** | 겁(劫)은 빼앗음이니, 밖에서 빼앗는 것을 겁이라 합니다. 십이장생의 도표에서 절지(絶地)에 놓입니다 |

### 3.3 망신(亡神)

망신은 겁살과 반대입니다——‘안에서 잃는 것을 망이라 한다(自內失之謂之亡)’. 겁살은 외부인이 와서 빼앗는 것이고, 망신은 자기 내부에서 문제가 생기는 것, 예컨대 판단을 그르치거나 스스로 기회를 망치는 것입니다. 다만 망신이 길신과 같은 기둥에 있으면 도리어 나쁜 일이 좋은 일로 바뀔 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| **구결(口訣)** | 寅午戌见巳，亥卯未见寅，巳酉丑见申，申子辰见亥<br>인오술(寅午戌)은 사(巳)를 보고, 해묘미(亥卯未)는 인(寅)을 보며, 사유축(巳酉丑)은 신(申)을 보고, 신자진(申子辰)은 해(亥)를 봅니다 |
| **의미** | 망(亡)은 잃음이니, 안에서 잃는 것을 망이라 합니다. 겁은 오행의 절처에 있고, 망은 오행의 왕처에 있습니다 |
| **주의** | 「망신이 명에 들면 화가 가볍지 않으니, 온갖 꾀를 다하여도 마음이 편치 않다.」 다만 길신과 같은 기둥에 있으면 도리어 좋은 일이 됩니다 |

### 3.4 천라지망(天羅地網)

진(辰)은 천라, 술(戌)은 지망이며, 남자는 천라를 꺼리고 여자는 지망을 꺼립니다. 대운·유년에서 천라지망을 만나면 관사·옥살이나 심한 질병·재앙이 생기기 쉬우므로 특히 유의해야 합니다.

| 항목 | 내용 |
| --- | --- |
| **정의** | 진(辰)은 천라, 술(戌)은 지망입니다. 남자는 천라를 꺼리고, 여자는 지망을 꺼립니다 |
| **작용** | 질병의 재앙과 옥살이의 재앙을 주관하며, 대운·유년에서 이것을 만나면 사람에게 불리합니다 |

### 3.5 음양착오(陰陽差錯)

음양착오는 열두 개의 특정 일주로, 가정 관계의 불협화를 주관합니다. 여명에 지니면 시댁과 화목하기 어렵고, 남명에 지니면 처가와 시비가 생기기 쉽습니다.

| 항목 | 내용 |
| --- | --- |
| **찾는 법** | 병자(丙子)·정축(丁丑)·무인(戊寅)·신묘(辛卯)·임진(壬辰)·계사(癸巳)·병오(丙午)·정미(丁未)·무신(戊申)·신유(辛酉)·임술(壬戌)·계해(癸亥) 열두 날 |
| **여명** | 시부모와 정이 적고, 동서와 화목하지 못하며, 시댁이 냉퇴합니다 |
| **남명** | 외가와 멀어지고, 처가와 시비가 많아 정이 적습니다 |

### 3.6 고란살(孤鸞煞)

고란살은 고독과 혼인의 순조롭지 못함을 주관합니다. 찾는 법은 일주와 시주에 고란살의 날 가운데 어느 두 조(組)가 동시에 나타나는 것으로, 단일 신살의 판단보다 한층 신중해야 합니다——두 자리에 동시에 나타나야 비로소 고란격을 이룹니다.

| 항목 | 내용 |
| --- | --- |
| **찾는 법** | 을사(乙巳)·정사(丁巳)·신해(辛亥)·무신(戊申)·임인(壬寅)·무오(戊午)·임자(壬子)·병오(丙午). 사주의 일주와 시주에 위의 어느 두 조가 동시에 나타나면 해당합니다 |
| **의미** | 고독, 순조롭지 못함, 남편을 극하고 아내를 극함을 주관합니다 |

## 四、신살 운용의 중요 원칙

### 4.1 《명리약언(命理約言)》의 정벽한 논술

> 

**해석**: 사람의 명의 길흉은 모두 격국과 운기에 의해 결정되는데, 어찌 우연히 신살이 맞았다고 그것을 믿을 수 있겠습니까?

### 4.2 신살에 대한 올바른 태도

- **주차가 분명해야 함**: 오행 생극, 십신 관계, 격국 판정이 명리학의 주체입니다
- **신살은 보조**: 신살은 신조(神助)의 요소로, 보조 참고에 그쳐야 하며 주객이 전도되어서는 안 되고, 지나치게 해석해서도 안 됩니다

### 4.3 학습 제안

- **오행 생극**: 핵심
- **십신 관계**: 초석
- **격국 판정**: 관건
- **신살**: 신조 요소, 보조 참고에 그침

**광초가(邝楚嘉) 안(按)**: 신살은 참고용일 뿐이며, 지나치게 해석해서는 안 됩니다.

## 본장 소결

2. **중성 신살** – 역마(이동), 화개(철학·종교), 장성(권력), 도화(정감), 록신(작록), 괴강(강렬), 양인(포악)
3. **흉신류 신살** – 공망(구하여도 얻지 못함), 겁살(외부의 탈취), 망신(내부의 상실), 천라지망(옥살), 음양착오(혼인이 순조롭지 못함), 고란살(고독)
4. **핵심 원칙** – 오행 생극과 십신 관계를 위주로 하고 신살은 보조로 하며, 주객이 전도되어서는 안 됩니다
