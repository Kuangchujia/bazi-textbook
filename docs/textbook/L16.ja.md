# 第16課 神煞

[简体中文](/textbook/L16/) ｜ [繁體中文](/zh-hant/textbook/L16/) ｜ [English](/en/textbook/L16/) ｜ **日本語** ｜ [한국어](/ko/textbook/L16/)

## 一、吉神類の神煞

吉神類の神煞は、八字のなかで正面的な補助の働きをする星神である。神煞を学ぶ第一歩は、以下に挙げる最もよく見られる吉神を覚えきることにある。

### 1.1 天乙貴人

天乙貴人は最も重要な吉神であり、凶に逢えば吉に転じ、難に遇えば祥を呈するを主とする。調べ方は日干を基準とし、地支に見ればすなわち貴人ありとする。口訣は歌謡のように見えるが、覚えきれば排盤の判断に大いに役立つ。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 甲戊并牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，庚辛逢虎马，此是贵人方<br>大意：甲・戊の日は丑・未に、乙・己は子・申に、丙・丁は亥・酉に、壬・癸は卯・巳に、庚・辛は寅・午に天乙貴人が現れる。 |
| **調べ方** | 日干より貴人を起し、地支に見る者を是とする |
| **作用** | 凶に逢えば吉に転ずるの星——四柱に貴人あれば、事に遇うて助くる人あり、危難の事に遇うて救済する人あり |

### 1.2 天徳貴人

天徳貴人は月令を基準として調べる。生まれ月が違えば天徳も違う。天徳は一生の平穏、病少なく災少なきを主とし、月徳と名を斉しくする吉祥の神煞である。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 正月生者见丁，二月生者见申，三月生者见壬，四月生者见辛，五月生者见亥，六月生者见甲，七月生者见癸，八月生者见寅，九月生者见丙，十月生者见乙，十一月生者见巳，十二月生者见庚<br>大意：正月生まれの者は丁を、二月は申を、三月は壬を、四月は辛を、五月は亥を、六月は甲を、七月は癸を、八月は寅を、九月は丙を、十月は乙を、十一月は巳を、十二月は庚を見る。 |
| **調べ方** | 四柱の年月日時に見る者を、天徳貴人ありと為す |
| **作用** | 人に天徳貴人あれば、一生平穏、病少なく災少なし |

### 1.3 月徳貴人

月徳は天徳とともに「天月二徳」と並称され、古人は二徳を仁慈善良の象とみなした。もし凶煞（七殺・劫煞など）が天月二徳と同柱なれば、その凶性は大いに減ずる——これは神煞を組み合わせて用いるうえでの重要な思路の一つである。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 寅午戌月生者见丙，申子辰月生者见壬，亥卯未月生者见甲，巳酉丑月生者见庚<br>大意：寅・午・戌月生まれの者は丙を、申・子・辰月生まれの者は壬を、亥・卯・未月生まれの者は甲を、巳・酉・丑月生まれの者は庚を見る。 |
| **作用** | 天月二徳あれば、その人は愷悌慈祥、人に待つに至誠仁厚。煞が天月徳を帯びれば、明敏果決にして仁厚；食傷が天月徳を帯びれば、聡明秀慧にして仁厚。二徳は天徳を重とし、月徳はこれに次ぐ |

### 1.4 太極貴人

太極貴人は聡明好学、深奥な学問を研鑽するを好むを主とする。太極を命に帯びる人は、哲学・歴史・宗教・玄学などの科目に、しばしば生来の親近感を抱く。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 甲乙生人子午中，丙丁鸡兔定亨通，戊己两干临四季，庚辛寅亥禄丰隆，壬癸巳申偏喜美，值此应当福气钟<br>大意：甲・乙の人は子・午、丙・丁の人は卯・酉、戊・己の両干は辰・戌・丑・未の四季、庚・辛は寅・亥、壬・癸は巳・申——これに値する者は福気集まるとなる。 |
| **作用** | 聡明好学、研鑽の勁あり、文史・哲・宗教などの科目を好むを主とする。人となり正直、事を為すに始めあり終わりあり |

### 1.5 文昌

文昌は文采と学業を主とし、文昌を命に帯びる人は通常、気質が文雅にして学を好み上進する。試験運・学習運のよい人は、八字に文昌星を帯びていることが多い。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 甲乙巳午报君知，丙戊申宫丁己鸡。庚猪辛鼠壬逢虎，癸人见卯入云梯<br>大意：甲は巳、乙は午、丙・戊は申、丁・己は酉、庚は亥、辛は子、壬は寅、癸は卯を見る。これに遇う者は雲梯に入るがごとく立身するとなる。 |
| **調べ方** | 年干または日干を主とし、四柱の地支に見る者を是とする |
| **作用** | 文昌、命に入れば、聡明人に過ぐ、凶に逢えば吉に転ずるを主とする。気質雅秀、挙止温文、新しい知識を好み学び、上進心を具う |

### 1.6 天医

天医は健康と医術を主とする。天医を命に帯び、かつ生旺なる人は、自身の身体が健やかなのみならず、医療・心理・養生など健康に関わる職業に特に適する。

| 項目 | 内容 |
| --- | --- |
| **調べ方** | 正月生まれは丑を見、二月生まれは寅を見、三月生まれは卯を見、四月生まれは辰を見、五月生まれは巳を見、六月生まれは午を見、七月生まれは未を見、八月生まれは申を見、九月生まれは酉を見、十月生まれは戌を見、十一月生まれは亥を見、十二月生まれは子を見る。月支をもって他の地支を調べる |
| **作用** | 生旺にしてさらに貴人の相生助あれば——身体健壮、特に医務の仕事および心理学・哲学などに適す |

## 二、中性の神煞

中性の神煞は、それ自体に固定した吉凶はなく、具体的な命局に合わせて判断するを要する。

### 2.1 駅馬

駅馬は走動・奔波・遷移を主とする。駅馬を命に帯びる人は天性よく動き、じっとしていられない。商人・軍人・外交官・営業など、常に出張したり職を移したりする人は、八字に駅馬星を帯びていることが多い。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 申子辰马在寅，寅午戌马在申，巳酉丑马在亥，亥卯未马在巳<br>大意：申・子・辰の者は寅に駅馬あり、寅・午・戌の者は申に、巳・酉・丑の者は亥に、亥・卯・未の者は巳に駅馬ありとなる。 |
| **調べ方** | 日支を主とし、四柱にこれに臨む者を馬星と為す |
| **作用** | 馬は走動・奔馳の象。人をして動を好ましめ、必ず東西南北を走り遍ねくの行あり。商人・軍人・外交人員など、常に出張・走動する者は馬星を帯ぶる多し |

### 2.2 華蓋

華蓋は孤独なれど深みのある星である。華蓋を命に帯びる人は賑やかな場を好まず、独処して考えるを好み、哲学・宗教・玄学・芸術に生来の興味を抱く。多くの学者・修行者・芸術家の八字に華蓋が帯びている。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 寅午戌见戌，亥卯未见未，申子辰见辰，巳酉丑见丑<br>大意：寅・午・戌の者は戌を、亥・卯・未の者は未を、申・子・辰の者は辰を、巳・酉・丑の者は丑を見る——これを華蓋となる。 |
| **調べ方** | 年支または日支を主とする |
| **作用** | 性情恬淡、雅潔高致、資質聡敏にして、文才と芸術性に富み、哲学・宗教に傾く |

### 2.3 将星

将星は権力の星であり、組織・統率の能力を主とする。将星を命に帯びる人は人を畏服せしむるの威あり、管理職に適する。ただし将星が死絶あるいは沖破の状態にあってはならず、さもなくば名ありて実なしとなる。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 寅午戌见午，巳酉丑见酉，申子辰见子，亥卯未见卯<br>大意：寅・午・戌の者は午を、巳・酉・丑の者は酉を、申・子・辰の者は子を、亥・卯・未の者は卯を見る——これを将星となる。 |
| **調べ方** | 年支または日支を主とし、四柱の地支に見る者を是とする |
| **作用** | 権力の星にして、組織・統率・指揮の才能を具え、人を畏服せしむるの威あり。ただし死絶・沖破なる者は不利 |

### 2.4 桃花（咸池）

桃花は人縁と情縁を主とし、最もよく知られ、また最も誤判されやすい神煞である。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 申子辰在酉，寅午戌在卯，巳酉丑在午，亥卯未在子<br>大意：申・子・辰の者は酉に、寅・午・戌の者は卯に、巳・酉・丑の者は午に、亥・卯・未の者は子に桃花ありとなる。 |
| **調べ方** | 年支または日支をもって四柱の他の地支を調べる |
| **注意** | 桃花が羊刃を帯びれば、多学多能を主とすれども、免れず疾多し。もし歳運に桃花の沖を見れば、色によりて刑を犯す |

### 2.5 禄神

禄神はすなわち十干の臨官の位であり、爵禄と福気を代表する。禄が年支にあれば歳禄、月支にあれば建禄、日支にあれば専禄、時支にあれば帰禄——なかでも帰禄（時柱）が最も吉利にして、「青雲路を得る」の象がある。ただし禄は空亡に落つるか沖に逢うを忌み、これを「破禄」と称し、反って衣食足らずを主とする。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 甲禄在寅，乙禄在卯，丙戊禄在巳，丁己禄在午，庚禄在申，辛禄在酉，壬禄在亥，癸禄在子<br>大意：甲の禄は寅に、乙の禄は卯に、丙・戊の禄は巳に、丁・己の禄は午に、庚の禄は申に、辛の禄は酉に、壬の禄は亥に、癸の禄は子にあるとなる。 |
| **分類** | 年支→歳禄、月支→建禄、日支→専禄、時支→帰禄 |
| **注意** | 禄が空亡に落ち、あるいは沖を犯すを破禄と謂い、貴人は停職剥官、常人は衣禄足らず |

### 2.6 魁罡

魁罡は特定の四つの日柱——壬辰・庚戌・庚辰・戊戌である。魁罡を命に帯びる人は性格剛烈、正直果断、悪を仇むが如し。ただし魁罡は日主健旺にして初めてその働きを発し、日主弱き魁罡は反って挫折に遭いやすい。

| 項目 | 内容 |
| --- | --- |
| **四柱** | 壬辰、庚戌、庚辰、戊戌 |
| **条件** | 日柱に見る者を是とし、日主健旺なるを要す |
| **性格** | 剛烈・正直・勇猛、個性は剛直、胸に城府なく、悪を仇むが如く、聡明果断、権力を巧みに用いる |

### 2.7 羊刃（陽刃）

羊刃はすなわち陽干の帝旺の位（甲卯・丙戊午・庚酉・壬子）であり、禄過ぎれば則ち刃生ずるの極限状態である。羊刃は剛烈暴戾、身強の者がこれに遇えば火に油を注ぐが如く、身弱の者に羊刃あれば反って身を助くる良きものとなる。もし天月二徳が同柱なれば、羊刃の凶性を解消しうる。

| 項目 | 内容 |
| --- | --- |
| **調べ方** | 甲卯乙寅丙戊午，丁己巳庚酉辛申，壬子癸亥<br>大意：甲は卯、乙は寅、丙・戊は午、丁・己は巳、庚は酉、辛は申、壬は子、癸は亥——日干に対してこの地支を見る者を羊刃となる。 |
| **特性** | 剛烈・暴戾・激発・急躁。禄過ぎれば則ち刃生じ、功成りて当に退くべきに退かず |
| **身強** | 羊刃を喜ばず、天月二徳の相助あれば災いを消しうる |
| **身弱** | 羊刃あれば身を助くるを得 |

## 三、凶神類の神煞

凶神類の神煞は、阻害・損失・不利の要素を代表する。神煞は参考に供するのみであり、過度に読み解くべきではない。

### 3.1 空亡

空亡は最も特殊な一類の凶神である——それは「悪」ではなく「空」である。財を求めて空亡を見れば、求めて得ず；官を求めて空亡を見れば、虚しくその名あり。空亡は落ちる柱位によって、影響する親縁の領域が異なる。

| 項目 | 内容 |
| --- | --- |
| **調べ方** | 日柱を主とし、柱中の年月時支に見る者を空亡と為す |
| **意味** | 求めて得ざる、すなわち空亡 |

空亡が落ちる柱位が違えば、人生のそれぞれ異なる面が「空しく」なる。以下の表はその判断を速やかにする助けとなる。

| 位置 | 情報 |
| --- | --- |
| **年支空亡** | 祖縁淡薄、祖輩に早世の人あり、または祖業空し；母空（辞世／再嫁／出走／母、子を顧みず） |
| **月支空亡** | 家庭観念淡薄、兄弟姉妹なし、あるいは兄弟姉妹に頼るなし |
| **時支空亡** | 子息に不利、子女なし、子女の流産多し、夭折、身体の不調を主とする |

### 3.2 劫煞

劫煞は外部の力があなたの財物を劫奪することを代表する——「自外夺之谓之劫」。劫煞がどの柱位に落ちるかによって、その柱位に対応する人や事が外部の者に侵奪されやすい。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 申子辰见巳，亥卯未见申，寅午戌见亥，巳酉丑见寅<br>大意：申・子・辰の者は巳を、亥・卯・未の者は申を、寅・午・戌の者は亥を、巳・酉・丑の者は寅を見る——これを劫煞となる。 |
| **意味** | 劫は奪なり、外よりこれを奪うを劫と謂う。十二長生のなかでは絶地に処す |

### 3.3 亡神

亡神は劫煞と相反する——「自内失之谓之亡」。劫煞は外から奪うもの、亡神は自己の内部に問題が生ずるもの、たとえば判断の誤り、自ら好機を潰すことなどである。ただし亡神が吉神と同柱なれば、反って悪事が好事に転じうる。

| 項目 | 内容 |
| --- | --- |
| **口訣** | 寅午戌见巳，亥卯未见寅，巳酉丑见申，申子辰见亥<br>大意：寅・午・戌の者は巳を、亥・卯・未の者は寅を、巳・酉・丑の者は申を、申・子・辰の者は亥を見る——これを亡神となる。 |
| **意味** | 亡は失なり、内よりこれを失うを亡と謂う。劫は五行の絶処にあり、亡は五行の旺処にあり |
| **注意** | 「亡神入命祸非轻，算尽机关心不宁。」ただし吉神と同柱なれば、反って好事と成る |

### 3.4 天羅地網

辰は天羅、戌は地網、男は天羅を忌み、女は地網を忌む。大運・流年に天羅地網に遇えば、訴訟・牢獄あるいは重い疾病の災いを生じやすく、特に留意を要する。

| 項目 | 内容 |
| --- | --- |
| **定義** | 辰は天羅と為し、戌は地網と為す。男は天羅を忌み、女は地網を忌む |
| **作用** | 疾病の災い、牢獄の災いを主とし、大運・流年にこれに遇えば、人に不利 |

### 3.5 陰陽差錯

陰陽差錯は十二の特定の日柱であり、家庭関係の不調和を主とする。女命にこれを帯びれば夫家と円満に折り合い難く、男命にこれを帯びれば妻家と是非を生じやすい。

| 項目 | 内容 |
| --- | --- |
| **調べ方** | 丙子、丁丑、戊寅、辛卯、壬辰、癸巳、丙午、丁未、戊申、辛酉、壬戌、癸亥の十二日 |
| **女命** | 公姑と睦まず、妯娌足らず、夫家冷退す |
| **男命** | 外家を退け、妻家と是非多く睦まずを主とする |

### 3.6 孤鸞煞

孤鸞煞は孤独と婚姻の不順を主とする。調べ方は、日柱と時柱に孤鸞煞の日が同時に現れること、すなわち右のうち任意の二組が日柱・時柱に揃うことによる。これは単独の神煞による判断より慎重を要する——二つの位置に同時に現れて初めて孤鸞格を成すのである。

| 項目 | 内容 |
| --- | --- |
| **調べ方** | 乙巳、丁巳、辛亥、戊申、壬寅、戊午、壬子、丙午。四柱の日時に右のうち任意の二組が同時に現るる者を是とする |
| **意味** | 孤独・不順・夫を剋し妻を剋すを主とする |

## 四、神煞運用の重要原則

### 4.1 『命理約言』の精到な論述

> 

**釈義**：人の命の吉凶は、いずれも格局と運気によって定まる。偶々神煞が符合したというだけで、どうしてこれを信ずることができようか。

### 4.2 神煞に対する正しい態度

- **主次分明**：五行の生剋、十神の関係、格局の判定が命理学の主体である
- **神煞は輔**：神煞は神助の要素であり、あくまで補助的な参考にとどめ、主客を転倒してはならず、過度に読み解くべきではない

### 4.3 学習の建議

- **五行の生剋**：核心
- **十神の関係**：礎
- **格局の判定**：鍵
- **神煞**：神助の要素、あくまで補助的な参考

## 練習

### 練習1：天乙貴人

**問い**：甲木の日干の人、地支に何を見れば天乙貴人となるか。

A. 鼠・猿（子・申）<br>B. 牛・羊（丑・未）<br>C. 猪・鶏（亥・酉）<br>D. 虎・馬（寅・午）

???+ "答え"
    正解：B
    **天乙貴人の口訣**——「甲戊并牛羊」。甲の日干の人は、地支に丑（牛）・未（羊）を見るを天乙貴人とする。

### 練習2：文昌

**問い**：文昌が命に入る人には、通常どのような特徴があるか。

A. よく動き、東西南北を歩き回る<br>B. 聡明人に過ぎ、凶に逢えば吉に転じ、気質は雅秀<br>C. 剛烈暴戾にして、急躁衝動<br>D. 婚姻不順にして、公姑と睦まず

???+ "答え"
    正解：B
    文昌入命：聡明人に過ぎ、凶に逢えば吉に転じ、気質は雅秀、挙止は温文、新しい知識を好み学び、上進心を具う。

### 練習3：空亡

**問い**：空亡が年支にある場合、何を表すか。

A. 子息に不利<br>B. 祖縁淡薄にして、祖業空し<br>C. 走動頻繁<br>D. 権力が大きい

???+ "答え"
    正解：B
    **年支空亡**：祖縁淡薄、祖輩に早世の人あり、または祖業空し
    時支空亡：子息に不利
    月支空亡：家庭観念淡薄

### 練習4：神煞原則

**問い**：『命理約言』によれば、八字を学ぶ重点はどこに置くべきか。

A. 各種の神煞の口訣を暗記する<br>B. 天羅地網の各種の変化を研究する<br>C. 五行の生剋、十神の関係、格局の判定<br>D. すべての神煞の調べ方を記憶する

???+ "答え"
    正解：C
    **核心原則**：五行の生剋、十神の関係、格局の判定が命理学の主体である。神煞はあくまで補助的な参考にとどめ、主客を転倒してはならない。

### 練習5：神煞の識別

**問い**：以下のうち、どの神煞が「走動・遷移・奔波」を表すか。

A. 華蓋<br>B. 駅馬<br>C. 魁罡<br>D. 桃花

???+ "答え"
    正解：B
    **駅馬**：走動・奔馳の象 ✓
    華蓋：哲学・宗教の傾向
    魁罡：剛烈正直
    桃花：情感の縁
