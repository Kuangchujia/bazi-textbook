# 第8課 十神の排盤

[简体中文](/textbook/L08/) ｜ [繁體中文](/zh-hant/textbook/L08/) ｜ [English](/en/textbook/L08/) ｜ **日本語** ｜ [한국어](/ko/textbook/L08/)

## 一、天干の同性と異性

### 1.1 同性・異性の定義

| 関係 | 定義 | 例（甲木を日元とする） |
| --- | --- | --- |
| 同性 | 日元と陰陽属性が同じ | 甲が丙を見る（甲は陽、丙は陽） |
| 異性 | 日元と陰陽属性が異なる | 甲が乙を見る（甲は陽、乙は陰） |

日元を中心とし、他の天干と日元との陰陽関係が十神の正偏を決める。

核心原理：十神に正偏の別があるのは、ひとえに陰陽の異同による——同性は偏、異性は正。

### 1.2 実戦判断・邝楚嘉の経験分享

邝楚嘉按：十神を学び始めた者が最も恐れるのは机上の空論である。二十余年の実戦経験が私に三つの鉄則を教えた。

1. 陰陽を先に断じ、十神を後から推す。一つの天干を見たとき、第一の反応は「これは何の十神か」ではなく、「それが日干と同陰同陽か、それとも陰陽が異なるか」であるべきである。陰陽を判じれば正偏は即座に分かれる——十枚の表を覚えるより速い。
2. まず自分の八字を覚える。自分の八字を「模範解答」とする——あなたが甲の日干なら、庚を見れば七殺（QiSha）、辛を見れば正官（ZhengGuan）である。自分の十神を徹底して覚え込めば、他の日干に出会ったときは「立場を置き換えて考える」だけでよい。
3. 生剋関係は名称よりも重要である。十神の名称はゆっくり覚えればよいが、五類の生剋関係は条件反射でなければならない——生我、同我、我生、我克、克我。この五つの関係は十の名称よりはるかに重要である。初学者が「食神（ShiShen）」「傷官（ShangGuan）」の記憶に焦り、生剋の本質を疎かにするのは、断命に誤りが頻出する根源である。

## 二、日干（日元）とは何か

八字予測では、出生当日の干支の組合せ（日柱）のうちの天干をもって求測者を代表させる。これを日干、またの名を日元という。

予測において、日元と他の七つの干支との関係・組合せは、命主の性格の特徴、才能の潜在力、事業発展の方向などの情報を明らかにする。

例：八字が壬戌年 癸丑月 壬申日 庚申時であれば、日柱は壬戌日で、壬が日元である。すべての十神は壬を中心として推導する。

## 三、五行と日干の生剋関係

### 3.1 五類の基本関係

日元を中心として、五行の生剋は五類に分かれる。

『淵海子平』十神生剋の総訣——我を剋する者は正官・偏官、我を生ずる者は正印（ZhengYin）・偏印（PianYin）、我が剋する者は正財（ZhengCai）・偏財（PianCai）、我が生ずる者は傷官・食神、我と同じ者は劫財（JieCai）・敗財である。五行の生剋五関係を陰陽によって二分すれば十神となる、というのがこの訣の骨子である。原文は次のとおり。

> 

- 生我者（印綬）——私を生じ助ける五行。壬水の日元が金を見るがごとし（金は水を生ず）。父母・師長・貴人を主る。
- 同我者（比劫）——私と同類の五行。壬水の日元が水を見るがごとし。兄弟・朋友・同僚を主る。
- 我生者（食傷）——私が生じ助ける五行。壬水の日元が木を見るがごとし（水は木を生ず）。子女・学生・部下を主る。
- 我克者（財星）——私が剋制する五行。壬水の日元が火を見るがごとし（水は火を剋す）。妻財・管轄する物を主る。
- 克我者（官殺）——私を剋制する五行。壬水の日元が土を見るがごとし（土は水を剋す）。官鬼・上司・圧力を主る。

同一の関係でも、陰陽の配合が異なることによって正偏に分かれる——異性は正、同性は偏。『淵海子平』に曰く、「正官者，阴阳配合，相制有用；偏官者，隔七位而相克战，故谓之七煞」——正官は陰陽が配合し、相制して用を成す；偏官は七位を隔てて相剋し戦う、ゆえにこれを七煞と謂う。

『淵海子平』十神通変を論ず（甲の日干を例とする）——甲が甲を見れば比肩（BiJian）、乙なれば劫財、丙なれば食神、丁なれば傷官、戊なれば偏財、己なれば正財、庚なれば偏官すなわち七殺、辛なれば正官、壬なれば倒食すなわち偏印、癸なれば印綬すなわち正印である。

この訣の核心：十干は甲を標準とし、甲から癸まで順に十神に対応する——甲（比肩）、乙（劫財）、丙（食神）、丁（傷官）、戊（偏財）、己（正財）、庚（偏官）、辛（正官）、壬（偏印）、癸（正印）。日干を換えても位置は変わらず、十神がこれに随って変化する。甲の日干の対応関係を覚えることが、十神通変の「総鍵」である。

五類の関係は、それぞれ陰陽によって正偏に分かれ、合わせて十神となる。以下、各類ごとに古典の出処と推導の例を挙げる——甲木（陽）と乙木（陰）を日元として対照する。

#### 生我者→印綬

印は蔭庇、綬は承受。正印は慈母のごとく、温和に滋養し、報いを求めない；偏印（梟神）は厳師のごとく、また扶持ありといえども、条件を帯びる。

『淵海子平』印綬を論ず——「生我者即印绶也。有官无印，即非真官；有印无官，反成其福。印绶之人智虑，一生少病，能饱食丰厚，享现成财禄」。我を生ずる者がすなわち印綬である。官ありて印なくんば、すなわち真の官に非ず；印ありて官なくんば、反ってその福を成す。印綬の人は智慮あり、一生病少なく、飽食豊厚にして、現成の財禄を享く。

#### 同我者→比劫

比肩は手足のごとく、同気連枝にして甘苦を共にする；劫財は競争者のごとく、また友また敵にして、利益の前に臨んでこそ真価が分かる。

『淵海子平』比劫を論ず——「比肩者，兄弟之义，同气相求。劫财者，败财也，克父及妻」。比肩は兄弟の義、同気相求むるなり。劫財は敗財なり、父及び妻を剋す。

#### 我生者→食傷

食神は涓涓たる細流のごとく、温和にして後勢あり、才能は自然に流露する；傷官は噴薄する泉のごとく、激烈にして外に放ち、鋒芒を露わす。

『淵海子平』食傷を論ず——「食神一名寿星，一名爵星。伤官务要伤尽；伤之不尽，官来乘旺，其祸不可胜言」。食神は一名寿星、一名爵星。傷官は務めて傷尽くすを要す；傷し尽くさざれば、官来たりて旺に乗じ、その禍は言うも勝えず。

#### 我克者→財星

正財は俸禄・給与のごとく、安定して持久し、細水長流である；偏財は意外の横財のごとく、来るも速く去るも速く、大起大落する。

『淵海子平』財星を論ず——「我克者为妻财。正财者，我以精神气力所换之物；偏财者，众人之财，流通之财也」。我が剋する者が妻財である。正財は、我が精神気力を以て換取する所の物；偏財は、衆人の財、流通の財である。

#### 克我者→官殺

正官は法度のごとく、規範ありて温和、約束のうちに保護を帯びる；七殺は猛虎のごとく、厳烈にして猛烈、いささか制御を失えばすなわち自らを反噬する。

『淵海子平』偏官を論ず——「人有偏官，如抱虎而眠。虽借其威足以慑群畜，稍失关防，必为其噬脐。有制伏则为偏官，无制伏则为七杀」。人に偏官あるは、虎を抱いて眠るがごとし。その威を借りて群畜を懾すに足れども、いささか関防を失えば、必ずその噬脐となる。制伏あればすなわち偏官と為し、制伏なければすなわち七殺と為す。

七殺は猛虎のごとし——御し得て適切であればすなわち己の用と為し、御し得ずんばすなわち己の害と為す。これは十神のうち最も「制化」を要する一位である。

以上の五類は、甲・乙二つの日元の十神推導を覚えれば、残りの八干は自然に触類旁通する。

## 五、十神の生剋関係

### 5.1 十神の相生

十神のあいだに相生し、一筋の完全なエネルギーの循環鎖を形成する。

印綬は比劫を生ず——長上が身を扶持し、根基が養いを得る。比劫は食傷を生ず——自身の力量が才能の輸出に転化する。食傷は財星を生ず——才能が現金化されて財富となる。財星は官殺を生ず——財富が権力・地位に転化する。官殺は印綬を生ず——圧力が反哺して学識・修養となる。

『淵海子平』——「有官无印，即非真官；有印无官，反成其福」。官殺が印綬を生ずるは、圧力が修養に化する要の一歩である。同性の相生は力が大きく、異性の相生は力が小さい。

### 5.2 十神の相剋

十神の相剋は命局中の五組の核心的な衝突を明らかにする。そのいずれもが、断命において「どこに問題が生じているか」を判断する核心の手がかりである。

官殺は比劫を剋す——権力が競争者を抑圧する。比劫は財星を剋す——兄弟朋友が財を分かつ、破財の象（比劫奪財）。財星は印綬を剋す——財を貪りて名声を壊し、学業に不利（財壊印）。印綬は食傷を剋す——才能を抑圧し、子女に不利（梟印奪食）。食傷は官殺を剋す——才能が権威に挑み、官非・是非を惹く（傷官見官）。

『淵海子平』剋の道を論ず——

- 「劫财者，败财也，克父及妻」——劫財は敗財、父及び妻を剋す。比劫が財星を剋し、比劫奪財、兄弟朋友が我が財を分かつ。
- 「财能伤印」——財は印を傷つけうる。財星が印綬を剋し、財壊印、財を貪りて名を損じ、利のゆえに義を失う。
- 「偏印夺食，主伤子息」——偏印が食を奪い、子息を傷つくるを主る。印綬が食傷を剋し、梟印奪食、才能が抑圧され、子女の縁が薄い。
- 「伤官见官，为祸百端」——傷官が官を見れば、禍百端と為す。食傷が官殺を剋し、傷官見官、才を以て上に犯し、是非を招く。
- 「七杀攻身，有制为贵」——七殺が身を攻む、制あれば貴と為す。官殺が比劫を剋し、七殺に制なければ身を攻め、制あれば権柄に化する。

同性の相剋は力大にして両立せず；異性の相剋は力小にして調和しうる。この五組の矛盾の核心的な化解の道は、第9課「五大経典矛盾」の一節に詳しい。

## 本章小結

1. 同性・異性 – 陽干は陽、陰干は陰；日元と陰陽が同じを同性、異なるを異性という
2. 日干（日元） – 日柱の天干、命主本人を代表し、一切の十神関係の中心
3. 五類の関係 – 生我者（印）、同我者（比劫）、我生者（食傷）、我克者（財）、克我者（官殺）
4. 十神の排法 – 十神は日元との五行生剋＋陰陽の異同によって正偏を定む
5. 十神の生剋 — 相生の循環：印→比劫→食傷→財→官殺→印；五組の経典的衝突：梟印奪食／比劫奪財／食神制殺／傷官見官／財壊印

## 練習

### 練習1：同性・異性

問い：甲木を日元とするとき、以下のどの天干が甲木と「異性」の関係にあるか。

1. A. 甲
2. B. 丙
3. C. 庚
4. D. 乙

???+ "答え"
    正解：D
    同性：日元と陰陽が同じ（甲は陽、甲・丙・戊・庚・壬は同性）
    異性：日元と陰陽が異なる（甲は陽、乙・丁・己・辛・癸は異性）
    D の乙木は陰木で、陽木の甲とは異性の関係にある

### 練習2：十神の識別

問い：甲木を日元とするとき、庚金に遇うのは何の十神か。

1. A. 正官
2. B. 七殺
3. C. 正印
4. D. 偏財

???+ "答え"
    正解：B
    推導の過程：
    1. 甲木は日元（陽木）
    2. 庚金の属性：庚は陽金、金は木を剋す（克我者）
    3. 同性にして我を剋する者は七殺
    同類の推導：
    甲が辛金に遇う：異性の克我 → 正官
    甲が壬水に遇う：同性の生我 → 偏印
    甲が癸水を見る：異性の生我 → 正印

### 練習3：十神の生剋

問い：以下のうち「財壊印」の正しい説明はどれか。

1. A. 印綬が食傷を剋し、才能を抑圧する
2. B. 食傷が官殺を剋し、官非を惹く
3. C. 財星が印綬を剋し、財を貪りて名声を壊す
4. D. 比劫が財星を剋し、兄弟が財を分かつ

???+ "答え"
    正解：C
    「財壊印」：
    財は財富・物質を代表する
    印は学識・名声・母を代表する
    財旺にして印を剋す：財を貪りて名声を壊し、学業に不利、母を剋し或いは母との関係が良くない

### 練習4：十神の実戦

問い：八字中の「比劫奪財」は通常何を表すか。

1. A. 財運亨通し、財富絶えず
2. B. 朋友兄弟に足を引っ張られ破財しやすい
3. C. 事業発展が順調
4. D. 身体健康

???+ "答え"
    正解：B
    「比劫奪財」：
    比劫は兄弟・朋友・同僚を代表する
    財星は財富・妻を代表する
    比劫奪財 ＝ 兄弟朋友が財を分かつ → 朋友に連累されやすく、合伙で破財し、銭財聚まらず
    実戦のヒント：
    八字中に「比劫奪財」が重ければ、投資に注意し、合伙に注意し、他人に金を貸すことに注意すべきである
