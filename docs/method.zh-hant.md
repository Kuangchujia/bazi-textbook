# 一體多面

一體多面，是指同一種太極之氣因動靜不同而分陰陽；放到具體命局中，其輕重與指向會隨觀察維度而改變。

## 三步次序

**定維度**　維度不定，結論必亂。先問看它的哪一面：性格、六親、健康、事業。同一正官，斷性格看正義感，斷婚姻看夫星得位，斷健康看官星被沖克。這一步對應第 3—9 課，天干、地支與十神類象。

**看力量**　力量不對，全盤皆廢。同一十神，強弱不同則天差地別。正官有力為權柄，無力為空銜；財星身強為富，身弱為累。這一步對應第 14—15 課，旺衰抑扶。

**觀組合**　組合不同，格局迥異。十神從不單獨行事。正官見印為官印相生，見傷官則傷官見官。這一步對應第 10—12 課，十神組合三部曲。

## 執一而論錯在哪

見比劫就想到奪財，見七殺就想到凶災。可比劫既奪財，也是合作夥伴；七殺雖攻身，有制便是偏官。

第 13 課有一個例子：一個八字裡印綬被財所破。斷學業，印被財壞，不吉；斷事業，要看官星是否得力。同一個八字，領域一換，結論就換。若只按「財壞印」一句斷下去，事業那一面就被抹掉了。

吉不永吉，凶不盡凶，全在角度與組合之間。

## 適用範圍

三步次序是讀盤的路子，不是斷語的公式。維度沒定就落結論，或者拿一個十神去套所有領域，都不在一體多面的用法之內。它給的是同一個命局在不同層面上的讀法，不給現成斷語。
