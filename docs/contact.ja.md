# 連絡と勘誤

教材、練習問題、付録は独学できます。行き詰まったところを溜め込む必要はありません。このページには三つのことだけを載せています。連絡経路、尋ねられること、範囲外のことです。

## 連絡先

**メール**：chirca@163.com

勘誤はメールでのご連絡をおすすめします。原文、スクリーンショット、修正方法を添えやすいためです。

**WeChat**：jiayanyide

ニックネームは「嘉言一得」、所在地は広東省掲陽です。QRコードを読み取る場合も、WeChat IDで検索する場合も同じアカウントです。

![WeChatのQRコード：嘉言一得](assets/wechat-contact.png)

追加するときは用件を明記してください。たとえば「教材の勘誤」や「第14課の旺衰」など。判別しやすくなります。

## 尋ねられること

- 教材内容に関する質問：ある判断の文が通読できない、ある箇所の導出がつながらない、ある例が本文と合わない、など。
- 誤りや表記の問題：引用文、年号、表の数値、例示の干支。この種の修正は[版権と版本の説明](rights.md)の版本記録に記されます。
- 開講済みの課程と教学サービスに関する相談。現状は[課程と教学サービス](courses.md)を参照してください。

勘誤を送る際は、課次、章節の見出し、該当する段落を明記してください。十七課の課次と章節番号は安定しており、項目が対応してこそ確認できます。スクリーンショットや原の文を添えられればさらに良く、往復を一回減らせます。

## 範囲外のこと

当サイトは個人が運営する静的サイトです。購入、注文、決済、申込の入口はなく、予約の仮押さえもありません。

教材と教学は理論的な訓練と方法の議論のみを行い、具体的な吉凶占卜サービスには関わりません。したがって個別の批命、排盤、選日の依頼は本ページでは受け付けず、送られてきても返信しません。教材と無関係な商業宣伝、相互紹介、運用代行も同様に返信しません。
