# 關於嘉言一得

## 作者簡介

鄺楚嘉（Chujia Kuang），筆名嘉言一得，廣東揭陽人，獨立研究者與傳統術數教學者。1996 年起研習傳統術數，長期從事四柱八字與奇門遁甲的學習、理論研究及教學體系整理，2013 年起開課授業。

除傳統術數研究與教學外，作者還開展中國傳統曆法與歷史天文研究，以及潮汕民俗與地方文化數據整理，相關成果分別通過專業網站、開放數據倉庫及學術歸檔發布。

## 治學與教學取向

八字學習可分幾段：早年讀典籍，中間在論壇裡長年看命例，後來隨師學習，再往後是編講義、開課。幾段之間不是替換關係，前一段的底子在後面一直要用。

學習四柱八字不能停在術語記憶與口訣套用。先掌握曆法、排盤、陰陽五行、天干地支與十神基礎，再理解十神組合、格局、用神與歲運之間的關係；次序顛倒，越往後越亂。

實際分析看完整命局的結構關係，同時結合時代背景、地域環境與現實條件。單個十神、單一符號或一句孤立斷語，都不能代替整體分析。

## 教材

《四柱八字基礎教材》四篇十七課、12+萬字，是二十餘年排盤實踐與十餘年教學經驗的整理。主線是作者自己的基礎教學體系，傳統典籍作補充與延伸閱讀。引古籍原文處隨文標書名，其餘為個人經驗與教學口徑。

## 專業方向

**四柱八字**：基礎班講排盤、陰陽五行、天干地支、十神、格局、旺衰、大運流年；研修班講取格、用神、相神、體用、成敗救應、刑沖會合與歲運。基礎班十七課、12+萬字，見[教材正文](textbook/L01.md)；研修班十八章、二十四萬餘字，另行成書，不在本庫。

**曆法與古天文**：二十四節氣交節時刻、干支換歲、二十八宿等公開數據集，收在 [kuangchujia.com](https://kuangchujia.com/)。
