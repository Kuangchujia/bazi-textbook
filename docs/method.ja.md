# 一体多面

一体多面とは、同じ太極の気が動静の違いによって陰陽に分かれることを指します。具体的な命局に置いては、その軽重と指向は観察する次元によって変わります。

## 三つの手順

**次元を定める**　次元が定まらなければ、結論は必ず乱れます。まずどの面を見るかを問う——性格、六親、健康、事業。同じ正官でも、性格を断じれば正義感を見、婚姻を断じれば夫星の得位を見、健康を断じれば官星の沖克を見ます。この段は第3〜9課、天干、地支と十神の類象に対応します。

**力量を見る**　力量が正しくなければ、盤全体が台無しになります。同じ十神でも強弱が異なれば天と地の差があります。正官は力があれば権柄となり、力がなければ空位となります。財星は身強なら富となり、身弱なら負累となります。この段は第14〜15課、旺衰抑扶に対応します。

**組合せを観る**　組合せが異なれば格局は大きく異なります。十神は決して単独では働きません。正官が印を見れば官印相生となり、傷官を見れば傷官見官となります。この段は第10〜12課、十神組合三部曲に対応します。

## 一つを執って論ずる誤りはどこにあるか

比劫を見れば財を奪うと考え、七殺を見れば凶災を考えがちです。しかし比劫は財を奪う一方で提携相手でもあり、七殺は身を攻めますが、制があれば偏官となります。

第13課に例があります。ある八字で印綬が財によって破られています。学業を断じれば、印が財に壊されて不吉です。事業を断じるには、官星が得力しているかを見る必要があります。同じ八字でも領域を切り替えれば結論も切り替わります。「財壊印」という一句だけに従って断じれば、事業の面が抹殺されてしまいます。

吉は永く吉ならず、凶は尽く凶ならず、すべては角度と組合せの間にあります。

## 適用範囲

三つの手順は読盤の道筋であり、断語の公式ではありません。次元を定めずに結論を下すこと、あるいは一つの十神ですべての領域に当てはめることは、一体多面の用法の内にはありません。これは同じ命局を異なる層面で読む方法を与えるものであり、出来合いの断語を与えるものではありません。
