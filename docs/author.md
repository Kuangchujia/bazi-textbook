# 关于嘉言一得

## 作者简介

邝楚嘉（Chujia Kuang），笔名嘉言一得，广东揭阳人，独立研究者与传统术数教学者。1996 年起研习传统术数，长期从事四柱八字与奇门遁甲的学习、理论研究及教学体系整理，2013 年起开课授业。

除传统术数研究与教学外，作者还开展中国传统历法与历史天文研究，以及潮汕民俗与地方文化数据整理，相关成果分别通过专业网站、开放数据仓库及学术归档发布。

## 治学与教学取向

八字学习可分几段：早年读典籍，中间在论坛里长年看命例，后来随师学习，再往后是编讲义、开课。几段之间不是替换关系，前一段的底子在后面一直要用。

学习四柱八字不能停在术语记忆与口诀套用。先掌握历法、排盘、阴阳五行、天干地支与十神基础，再理解十神组合、格局、用神与岁运之间的关系；次序颠倒，越往后越乱。

实际分析看完整命局的结构关系，同时结合时代背景、地域环境与现实条件。单个十神、单一符号或一句孤立断语，都不能代替整体分析。

## 教材编写理念

《四柱八字基础教材》是二十余年预测实践与十余年教学经验的系统整理。主线是作者自己形成的基础教学体系，传统典籍用于补充、比较与延伸阅读，不拿来当作体系的骨架。

书中的规则、口诀与取舍，出自二十余年的排盘实践与十余年的教学；引古籍原文处随文标书名，其余即个人经验与教学口径。

不同流派的口径、存在争议的问题，尽量交代来源与适用范围，不把个人理解直接说成各家共识。读的人需要知道哪一句是原文、哪一句是后人的归纳。

把完整教材免费公开，是希望读者能直接接触整套课程结构、理论内容与练习材料，通过系统阅读和独立练习理解这套方法。教材是个人教学体系的阶段性整理，不是对传统命理所有问题的最终定论。
