# 四柱八字基礎教材

邝楚嘉（嘉言一得）基礎班は四篇十七課、12万字以上。ここは基礎班教材原文の単一の情報源であり、オンライン閲覧サイトです。研修班は十八章、二十四万字余りで、別途編成され、本ライブラリには含まれません。

全書は陰陽五行と干支から手を付け、順に天干五合、地支の関係、八字の排法、長生十二宮、十神の排法、十神の類象、十神の組合せ、旺衰抑扶、神煞と大運流年を扱います。各課は一つのまとまりをなし、前後に承接があり、最初から読むことも、必要に応じて一課だけ取り出すこともできます。

## 二つの専用入口

- [一体多面方法論](method.md)　教材の中核的な読盤次序：次元を定め、力量を見、組合せを観る。
