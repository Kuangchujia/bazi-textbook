# 四柱八字基礎教材

鄺楚嘉（嘉言一得）基礎班四篇十七課、12+萬字。此處是基礎班教材原文的單一內容源與在線閱讀站；研修班十八章、二十四萬餘字，另行編排，不在本庫。

全書從陰陽五行與干支起手，依次講天干五合、地支關係、八字排法、長生十二宮、十神排法、十神類象、十神組合、旺衰抑扶、神煞與大運流年。每課自成一段，前後有承接，可從頭讀，也可按需單取一課。

## 相關站點

本站是《四柱八字基礎教材》的閱讀與引用入口，另有三個站點，方向各自分開：

- [術數網 jiayanyide.com](https://jiayanyide.com/)：同一作者的術數主站。十七課在本站是排過版的閱讀本，主站有每課的完整原文、例題與摺疊答案，另有[術語詞典](https://jiayanyide.com/bazi/glossary/terms/)（四柱、十神、藏干、用神、格局等詞條）與專題研究。要對照原題與擴展閱讀，去主站；要按課連續讀，在本站。
- [中國曆法與歷史天文 kuangchujia.com](https://kuangchujia.com/)：節氣與歲首的更替、干支紀日的推算、二十八宿宿度的考據與數據。曆法考據與本教材屬兩套體系，一處的結論不為另一處作背書。
- [潮俗網 chaoshanwiki.com](https://chaoshanwiki.com/)：潮汕民俗數字知識庫，與本站無內容交疊。

機器可讀的站點導讀見 [llms.txt](https://bazi-textbook.jiayanyide.com/llms.txt)，全站頁面清單見 [sitemap.xml](https://bazi-textbook.jiayanyide.com/sitemap.xml)。
